# 밀고 당기는 도시

초등 4학년 자석 탐구 웹게임. 밀이·당이와 길을 따라 5개 구역을 고치고, 직접 조작한 실험 증거와 도구를 모아 자신의 발명품을 도시 복구에 사용한다.

## 실행

Node.js 22.12 이상 권장. 프로젝트 폴더에서 실행한다.

```powershell
npm install
npm run dev -- --port 5173
```

미리보기: http://localhost:5173/

이미 실행 중인 서버가 있으면 해당 주소를 먼저 연다. 서버를 종료하거나 PC를 재시작한 경우 위 명령으로 다시 실행한다.

현재 검수 주소 `http://127.0.0.1:5174/`를 다시 실행하려면 `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`를 사용한다. 로컬 서버가 종료되면 열린 화면에 남아 있는 글자와 달리 새 이미지·영상은 불러올 수 없으므로, 서버 실행 후 페이지를 새로고침한다. 진행 기록을 이어가려면 기존과 같은 주소·포트를 사용한다.

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

배포용 출력은 `dist/`에 생성된다. 외부 서비스 배포는 하지 않았다.

## 최신 개편 · 2026-10-24

10개 활동에 **예상 → 직접 실험 → 주장과 근거 → 새 상황 적용** 흐름을 적용했다. 각 구역은 두 활동과 두 응용 문제로 이어지며, 실제 조작 증거가 있어야 완료된다. 철 분류·운반, 고장 원인 진단, 양쪽 극 복원, 왕복 청소, 중간 정차·역방향 배송, 시제품 시험을 강화했다. [설계·변경 기록](docs/PRODUCTION-UPGRADE-20261024.md), [최종 점검](docs/reviews/FINAL-CHECK-20261024.md).

직접 생성한 재료 6종·실험 도구 6종, 구역 장면, 자석 문과 안내 로봇을 적용했다. 조작물과 기록 그림에도 실제 에셋을 사용하며 N/S 표시와 힘·이동 경로는 과학 모형에 맞춰 표시한다. [이미지 제작·검증 기록](docs/ART-PRODUCTION-20261024.md).

## 이전 개편 · 2026-10-22

2026-10-22: 구역 완료 후 12초 개념 모션 그래픽 5편, 보조 캐릭터 **자꾸**의 상태별 힌트, 실험 전후 위치 비교 슬라이더, 거리 표시·조작 경로·고리 반응 애니메이션, Kenney CC0 효과음 8종을 적용했다. 연구 가방·보고서는 구역별 탭으로, 팝업·설정·인증서는 태블릿과 전자칠판용 글자·간격으로 정리했다. [변경·검증 기록](docs/LEARNING-UX-20261022.md).

클릭·탭 중심 활동을 큰 실험대의 물체 조작으로 개편했다. 덮개 열기와 자석 유무 비교, 실제 자석으로 철 운반, 거리·종이 조건 분리, 극 추론·고리 재배치, 유리 밖 패드 추종, 당기기·밀기·역방향 배송, 부품 조립·수정·두 사용 조건 검증으로 이어진다.

지도 1장·활동실 5장·소품 6종을 프로젝트용으로 생성해 적용했다. 다음 실험에 쓰이는 도구 5종, 시설 복구, 움직이는 택배와 축제·인증서를 연결한다. 기존 v1/v2 완료 기록과 최초 증거는 보존한다. [활동 설계](docs/QUEST-UPGRADE-20261021.md), [최종 검증](docs/reviews/FINAL-CHECK-20261021.md), [그림 출처](docs/ART-PROMPTS-20261021.md)를 참고한다.

## 플레이

- 왼쪽 위 집·뒤로, 오른쪽 위 소리·설정 아이콘을 사용한다. 시작 화면은 소리·설정만 표시한다. 캐릭터를 눌러 도움말을 연다.
- Suno 메인 테마는 시작·게임 화면에서 반복하고 파이널 테마는 엔딩·인증서에서 이어서 재생한다. 설정에 배경음·효과음 켜기·끄기, 이야기, 연구 가방, 학생·교사용 가이드와 성취기준 원문이 있다. 엔딩·인증서는 실제 완료 후 열린다.
- 교사용 **모든 단계 한 번에 열기**는 시설 잠금을 풀어 시연하게 한다. 학습 완료·보상을 자동으로 채우지 않으며, 끄거나 새로고침하면 원래 기록으로 돌아간다.
- 메인 → 도시 탐험 → 건물 입장 → 활동 2개 → 연구 기록 획득 → 다음 구역 순서로 진행한다.
- 도시에서는 길·건물 클릭, 방향키 또는 화면 방향 버튼으로 이동한다. 건물 입구에 도착하면 입장할 수 있다.
- 실험은 터치·마우스로 조작하며, 드래그 활동에는 물체 선택 후 위치 누르기·이동 버튼·방향키 대안을 제공한다.
- 복구율은 0 → 20 → 40 → 60 → 80 → 95 → 최종 미션 후 100%가 된다.
- 완료한 구역의 재탐구는 최초 증거를 바꾸지 않는다.
- 마지막에 24초 2D 엔딩과 이름 입력·인쇄 가능한 인증서를 제공한다.

## 저장

로그인 없이 현재 브라우저의 IndexedDB에 자동 저장한다. 같은 주소·브라우저에서 이어할 수 있다. `localhost`와 `127.0.0.1`은 저장 공간이 다르다. 개발 검증에는 `127.0.0.1`을 사용했고, 전체 완주 검증 데이터는 `127.0.0.1`에 있고 `localhost`의 원래 기록과는 분리된다. 시크릿 모드, 저장 차단, 브라우저 데이터 삭제에 따라 보존되지 않을 수 있다. 저장 실패 시 화면에 알림을 표시한다.

## 파일

- `src/main.ts`: 화면 흐름, 도시 복구, 보고서·엔딩·인증서
- `src/expedition.ts`: 실제 그림 길 좌표·경로 탐색·카메라 추적·이동
- `src/mission-play.ts`: Canvas 과학 모형과 DOM 터치·키보드 타깃을 공유하는 10개 실험
- `src/mission-content.ts`, `src/mission-model.ts`: 질문·도구·활동 내용과 완료 증거 규칙
- `src/inquiry.ts`, `src/inquiry-content.ts`, `src/inquiry-model.ts`: 예상·실험·근거 설명·새 상황 적용과 완료 조건
- `src/production.css`, `src/inquiry.css`: 생성 이미지 기반 화면과 탐구 단계 UI
- `src/quest-ui.ts`, `src/quest.css`: 전체 화면·그림·폰트·UI 토큰
- `src/game-settings.ts`, `src/settings-content.ts`, `src/game-audio.ts`: 설정·가이드·로컬 음악·효과음과 합성 대체음
- `src/trial-records.ts`, `src/final-mission.ts`: 그림 기록과 최종 기본·선택 복구
- `src/domain.ts`, `src/storage.ts`: 과학 규칙·진행·증거·저장
- `src/art.ts`, `src/styles.css`, `src/adventure.css`, `src/tablet.css`, `src/ending.css`: 2D 그래픽과 UI
- `public/assets/quest/`: 새 지도·활동실·투명 소품의 WebP 배포본
- `assets/source/quest/`: 원본·생성 기록·해시·알파 검증
- `tests/`: 진행·물리·저장 실패 검증
- [설계 문서](docs/README.md), [구현·검증 기록](docs/IMPLEMENTATION.md)

새 활동은 `missionView → View.bind(Context)`로 연결하고 `mission-model.ts`의 완료 규칙에 실제 Trial 증거를 추가한다. 질문과 보상은 `mission-content.ts`에서 관리한다. 기존 최종 선택 도전은 이전 실험 모듈을 사용하므로 그 파일들을 임의 삭제하지 않는다.

데스크톱 브라우저에서 전체 완주와 화면 크기를 검증했다. 실제 태블릿·전자칠판 입력, 학생 이해도·소요 시간과 교실 30대 동시 접속은 별도 검증이 필요하다.

## Cloudflare 배포

`wrangler.jsonc`에 `magnet-city` 프로젝트와 빌드 폴더 `dist`를 지정했다. Cloudflare에 로그인된 Wrangler 4.x에서 아래 명령으로 배포한다.

```sh
npm ci
npm test
npm run build
wrangler pages deploy dist --project-name magnet-city --branch main
```

검증한 빌드 파일을 직접 올리는 방식이다. GitHub에 커밋만 푸시하면 자동으로 배포되는 구성은 아니다.
