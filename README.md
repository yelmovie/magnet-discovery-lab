# 밀고 당기는 도시

초등 4학년 자석 탐구 웹게임. 밀이·당이와 5개 구역을 탐험하고, 직접 실험해 찾은 자석의 성질을 이용해 주민을 도울 발명 카드를 만든다. 중앙 광장에서는 실험과 발명 기록을 수첩으로 정리한다.

## 납품 검토

전체 리뉴얼과 자동재생 1배/2배·교사 제어를 반영했다. 최종 검증과 확인 조건은 [납품 검토](docs/reviews/RELEASE-REVIEW-20261111-DELIVERY.md), [성적표](docs/reviews/SCORE-20261111-DELIVERY.md)를 참고한다. 후속 [작업 기록·커밋·공개 배포 대조](docs/reviews/RECONCILIATION-20261112.md)에서 검사 스크립트 복구와 재현 빌드 검증을 확인할 수 있다.

## 실행

Node.js 22.12 이상 권장. 프로젝트 폴더에서 실행한다.

```powershell
npm install
npm run dev -- --port 5173
```

미리보기: http://localhost:5173/

이미 실행 중인 서버가 있으면 해당 주소를 먼저 연다. 서버를 종료하거나 PC를 재시작한 경우 위 명령으로 다시 실행한다.

현재 검수 주소 `http://127.0.0.1:5174/`를 다시 실행하려면 `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`를 사용한다. 로컬 서버가 종료되면 열린 화면에 남아 있는 글자와 달리 새 이미지·영상은 불러올 수 없으므로, 서버 실행 후 페이지를 새로고침한다. 진행 기록을 이어가려면 기존과 같은 주소·포트를 사용한다.

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

배포용 출력은 `dist/`에 생성된다. 운영 배포 절차는 아래 「Cloudflare 배포」를 따른다.

## 퍼즐 액션 리뉴얼 · 2026-11-11

- 새 활동 2~8에 위기·단서·별과 시설 복구를 연결했다. 우편함 철판 맞추기, 철 부품 분류, 틈 너머 열쇠 구조, 밀고 당기는 두 문, 고리 승강 발판, 수조 청소, 세 구간 택배를 진행한다.
- 중앙 광장에서 철 부품 붙이기 → 거리 → 같은 극 → 유리 너머 조종의 연결 퍼즐을 풀면 기존 탐험 수첩과 엔딩·인증서로 이어진다. 지도 도깨비는 완료된 구역의 복구 기록에 맞춰 물러난다.
- 새 시도에 `puzzleRevision: 2`를 붙여 확장 규칙을 적용한다. 이전 진행 중 활동과 이미 시작한 수첩·수료 기록은 기존 경로로 이어진다. 저장 구조 버전은 2를 유지한다.
- 실제 드래그·자동재생·잘못된 조작·재시작 검사는 `scripts/puzzle-regression.cjs`에 있다. `TEST_FIXTURE`에는 전체 학습 경로 검사에서 생성한 합성 `student.json`을 지정한다.
- 현재 검증 결과와 실행 환경은 [인계 문서](docs/HANDOFF.md)와 [검토 기록](docs/reviews/RELEASE-REVIEW-20261111-FULL.md)에 정리했다.

## 탐구 기록 고도화 · 2026-11-06

- 우편함: 조립을 마치면 덮개를 닫기 전에 예상을 고르고, 닫은 뒤 처음 예상과 실제 결과를 나란히 비교한다. 예상이 달라도 실패로 처리하지 않는다.
- 자동재생: 기록에 `직접 해봄`과 `자동으로 관찰함`을 나눠 표시한다. 자동재생은 학생 대신 예상을 고르지 않고, 끝나면 본 결과를 한 번 고르게 한다(활동 1·3·7). 짝수 활동은 발견 정리가 같은 역할을 한다.
- 학습 증거: 발견 정리와 광장 수첩에서 처음 고른 답과 고친 답을 나눠 남긴다. 연구 가방과 내 실험 다시 보기에서 볼 수 있다.
- 완료 판정과 저장 구조는 바꾸지 않았다. 새 값이 없는 이전 기록은 표시를 지어내지 않고 질문으로 막지도 않는다. 자세한 내용은 [검토 기록](docs/reviews/INQUIRY-EVIDENCE-20261106.md)을 참고한다.

## 최신 고도화 · 2026-11-06

- 수업 내구성: 한 번 연 뒤에는 Wi-Fi가 끊겨도 새로고침된다(`public/sw.js`). 음악·음성·영상은 캐시하지 않고, 아직 열지 않은 화면의 그림은 처음 열 때 저장한다.
- 용량: 배포물을 56.7MB에서 약 27.8MB로 줄였다. 고리 3D 모델은 3.84MB에서 1.5MB가 됐다. 학생이 열 수 없던 상자·운반기 3D 시연은 코드와 모델을 `_unused/`로 옮겼다.
- 로딩: JS가 오기 전에도 로딩 화면이 보이고, 공유 썸네일(`public/og-image-v1.jpg`)과 해시 파일 장기 캐시(`public/_headers`)를 넣었다.
- 조작: 버튼과 입력칸은 48px 이상이고, 브라우저 뒤로가기는 게임의 이전 화면으로 간다. 3D가 끊기면 안내가 나온다.
- 기록: 손상된 저장은 읽을 수 있는 기록만 되살리고 원본을 `corrupt-backup`에 남긴다. 자동재생으로 얻은 관찰에는 "자동재생"이 표시된다. 활동별 학습 목표는 `src/activity-meta.ts`에 있고 교사 검수 전 상태로 표시된다.
- 구조: `src/mission-play.ts`를 활동 묶음별 `src/missions-*.ts`와 `src/mission-surface.ts`로 나눴다. 호출되지 않던 구형 활동과 Phaser를 뺐다.

## 최신 개편 · 2026-10-30

- **시작 화면**: 로고·소제목·시작하기/이어하기와 밀이·당이만 남긴 가운데 무대형 배치. 말풍선은 반투명 유리 질감·주아체 짧은 문장이고, 꼬리가 밀이 왼쪽·당이 오른쪽 머리끝으로 이어진다. 저장 기록이 없으면 '이어하기'는 비활성, 있으면 '시작하기'는 기록 초기화 확인 창을 연다.
- **도시 지도**: '현재 목적지' 칩·도우미 중복을 없애고, 지도 도구를 왼쪽 위 아이콘(손바닥 = 지도 밀기, 네모 = 전체 보기)으로 정리했다. 지도를 끌면 화면이 움직이고 걷기 시작하면 다시 밀이를 따라간다. 밀이·당이는 1.5배 작아졌고 당이는 밀이가 지나온 길을 그대로 따라 걷는다.
- **교사용 해금**: 실험을 끝내지 않아도 '다음 탐구로 → 발견 정리 → 다음 구역으로'가 항상 보이고 넘어간다. 학습 완료·보상은 여전히 채우지 않는다.
- **화면 정리**: 거리 게이지를 실험대 위 가장자리(세로 화면은 실험대 아래)로, 배송 상태 문구를 안내 라벨과 겹치지 않게, 전자칠판에서 보상 도구 칩을 HUD 아래로, 휴대폰의 '가로로 돌리면' 안내를 맨 아래로 옮겼다. 미리보기 보고서는 빈 화면 대신 안내 문구를 보여 준다.
- 검증: `npm test` 154개, `npm run build`, `npm run test:browser`(10개 활동·최종 복구·3개 해상도) 통과. 1920×1080·1280×800·1024×768·768×1024·390×844에서 전체 화면을 캡처해 화면 밖 버튼·말풍선 0건을 확인했다. 운영 배포는 하지 않았다.

## 이전 개편 · 2026-10-28

새 활동은 바로 실험대에서 시작하고, 구역마다 발견 한 가지를 정리한다. 매 활동의 예상 선택·규칙과 근거 재확인·별도 현장 의뢰 반복을 줄였다. 예상 질문과 개념 영상은 선택해서 볼 수 있다.

생활 장치와 미지 자석은 대표 한 개에 집중하고, 재료는 철·알루미늄·나무를 필수로 비교한다. 고리는 같은 배치에서 띄우기와 붙이기를 비교하고, 청소의 왕복 횟수 채우기와 배송의 중간 점검을 없앴다. 배송은 당기기·밀기 후 목적지 정차로, 발명은 현재 설계의 실제 사용 성공으로 확인한다. 보상 화면에서 다음 구역으로 바로 이동할 수 있다.

기존 진행 중 활동과 최초 완료 증거는 보존한다. 이번 변경은 로컬 개선이며 운영 배포는 하지 않았다. [10개 활동 전후·성취기준 대응·검증 범위](docs/reviews/LEARNING-FLOW-20261028.md)를 참고한다.

[직접 화면 조작으로 찾은 막힘과 후속 개선](docs/reviews/LEARNER-PLAYTEST-20261028.md)도 기록했다. 1024×768 브라우저에서 10개 활동과 인증서까지 직접 조작했고, 물체 잡기·재료 겹침·극 뒤집기·청소·배송 안내를 다듬었다. 현재 설계의 사용 성공 증거가 있으면 광장에서는 장착만으로 복구하고, 설계 변경이나 증거 누락 때는 다시 시험한다.

## 플레이

- 왼쪽 위 집·뒤로, 오른쪽 위 소리·설정 아이콘을 사용한다. 시작 화면은 소리·설정만 표시한다. 시작 화면의 밀이·당이를 누르면 말풍선이 열린다.
- Suno 메인 테마는 시작·게임 화면에서 반복하고 파이널 테마는 엔딩·인증서에서 이어서 재생한다. 설정에 배경음·효과음 켜기·끄기, 이야기, 연구 가방, 학생·교사용 가이드와 성취기준 원문이 있다. 엔딩·인증서는 실제 완료 후 열린다.
- 교사용 **모든 단계 한 번에 열기**는 시설 잠금을 풀어 시연하게 한다. 학습 완료·보상을 자동으로 채우지 않으며, 끄거나 새로고침하면 원래 기록으로 돌아간다.
- 메인 → 도시 탐험 → 건물 입장 → 활동 2개 → 연구 기록 획득 → 다음 구역 순서로 진행한다.
- 도시에서는 길·건물 클릭, 방향키 또는 화면 방향 버튼으로 이동한다. 지도를 끌어 둘러보고, 손바닥 아이콘을 다시 누르거나 걷기 시작하면 밀이에게 돌아온다. 건물 입구에 도착하면 입장할 수 있다.
- 실험은 터치·마우스로 조작하며, 드래그 활동에는 물체 선택 후 위치 누르기·이동 버튼·방향키 대안을 제공한다.
- 복구율은 0 → 20 → 40 → 60 → 80 → 95 → 최종 미션 후 100%가 된다.
- 완료한 구역의 재탐구는 최초 증거를 바꾸지 않는다.
- 처음 시작하면 17.5초 인트로 영상(수리 의뢰 → 단서 → 발명 공방)이 나오고, 마지막 복구 뒤에는 17.4초 엔딩 영상(발명품 성공 → 다시 움직이는 도시 → 축제 메달)이 나온다. 둘 다 오른쪽 위 **건너뛰기**로 마지막 카드까지 바로 넘어갈 수 있고, 자막·장소 태그·구역 도장은 화면 글자다. 상세는 `docs/STORY-VIDEO-20261101.md`.
- 엔딩 영상 뒤에 별명을 선택으로 입력해 인쇄할 수 있는 인증서를 제공한다.
- 화면 크기에 맞춰 실험대와 조작 버튼이 배치된다. 확대하거나 화면이 작으면 긴 페이지와 팝업을 스크롤해서 읽을 수 있다. 상세와 측정 방법은 `docs/RESPONSIVE-FIT-20261101.md`.

## 저장

로그인 없이 현재 브라우저의 IndexedDB에 자동 저장한다. 같은 주소·브라우저에서 이어할 수 있다. `localhost`와 `127.0.0.1`은 저장 공간이 다르다. 개발 검증에는 `127.0.0.1`을 사용했고, 전체 완주 검증 데이터는 `127.0.0.1`에 있고 `localhost`의 원래 기록과는 분리된다. 시크릿 모드, 저장 차단, 브라우저 데이터 삭제에 따라 보존되지 않을 수 있다. 저장 실패 시 화면에 알림을 표시한다.

## Cloudflare 배포

`wrangler.jsonc`에 `magnet-city` 프로젝트와 빌드 폴더 `dist`를 지정했다. Cloudflare에 로그인된 Wrangler 4.x에서 아래 명령으로 배포한다.

```sh
npm ci
npm test
npm run build
wrangler pages deploy dist --project-name magnet-city --branch main
node scripts/verify-release.mjs https://magnet-city.pages.dev
node scripts/release-smoke.cjs https://magnet-city.pages.dev test-results/release-smoke
```

`verify-release.mjs`는 `dist/`의 모든 파일을 운영에서 다시 받아 SHA-256을 비교하고, `release-smoke.cjs`는 두 해상도에서 첫 조립과 이어하기, 고리 3D, 발명 수첩과 인증서를 확인한다. 운영은 [2026-11-06 배포 기록](docs/reviews/RELEASE-REVIEW-20261106.md)을 참고한다.

검증한 빌드 파일을 직접 올리는 방식이다. GitHub에 커밋만 푸시하면 자동으로 배포되는 구성은 아니다.
