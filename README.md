# 밀고 당기는 도시

초등 4학년 자석 탐구 웹게임 MVP. 도시를 걸어 다니며 5개 구역의 10개 활동을 수행하고, 증거를 모아 마지막 자기 코어를 복구한다.

## 실행

Node.js 22.12 이상 권장. 프로젝트 폴더에서 실행한다.

```powershell
npm install
npm run dev -- --port 5173
```

미리보기: http://localhost:5173/

이미 실행 중인 서버가 있으면 해당 주소를 먼저 연다. 서버를 종료하거나 PC를 재시작한 경우 위 명령으로 다시 실행한다.

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

배포용 출력은 `dist/`에 생성된다. 외부 서비스 배포는 하지 않았다.

## 최신 개편 · 2026-10-18

10월 16일 태블릿 설계를 실제 앱에 반영했다. 질문 하나와 현재 행동, 큰 실험대, 자동 그림 기록·기록 서랍, 단계별 활동, 기본/선택 도전, 내 설계를 직접 작동시키는 최종 미션을 제공한다. 기존 v1 저장은 원본 백업 후 v2로 옮긴다.

실제 변경과 검증 범위는 [태블릿 개편 기록](docs/TABLET-IMPLEMENTATION-20261018.md)을 참고한다.

## 플레이

- 모든 화면 왼쪽 위의 집·뒤로 아이콘으로 메인 또는 직전 화면으로 이동한다. 오른쪽 위에는 연구 기록·소리·톱니바퀴 설정이 있다.
- 설정의 **관리자 전체 해금**을 켜면 10개 활동·보고서·최종 코어·엔딩·인증서를 한 번에 열 수 있다. 같은 창의 전체 화면 바로가기로 이동한다. 관리자는 이번 실행에서만 사용하는 미리보기이며, 끄거나 새로고침하면 원래 학습 기록으로 돌아간다.
- 메인 → 도시 탐험 → 건물 입장 → 활동 2개 → 연구 기록 획득 → 다음 구역 순서로 진행한다.
- 도시에서는 길·건물 클릭, 방향키 또는 화면 방향 버튼으로 이동한다. 건물 입구에 도착하면 입장할 수 있다.
- 실험은 터치·마우스로 조작하며, 드래그 활동에는 물체 선택 후 위치 누르기·이동 버튼·방향키 대안을 제공한다.
- 복구율은 0 → 20 → 40 → 60 → 80 → 95 → 최종 미션 후 100%가 된다.
- 완료한 구역의 재탐구는 최초 증거를 바꾸지 않는다.
- 마지막에 24초 2D 엔딩과 이름 입력·인쇄 가능한 인증서를 제공한다.

## 저장

로그인 없이 현재 브라우저의 IndexedDB에 자동 저장한다. 같은 주소·브라우저에서 이어할 수 있다. `localhost`와 `127.0.0.1`은 저장 공간이 다르다. 개발 검증에는 `127.0.0.1`을 사용했고, 전체 완주 검증 데이터는 `127.0.0.1`에 있고 `localhost`의 원래 기록과는 분리된다. 시크릿 모드, 저장 차단, 브라우저 데이터 삭제에 따라 보존되지 않을 수 있다. 저장 실패 시 화면에 알림을 표시한다.

## 파일

- `src/main.ts`: 화면 흐름, 도시 복구, 보고서·엔딩·인증서
- `src/city.ts`: 도시 화면의 Phaser 2.5D 픽셀 탐험
- `src/adventure.ts`, `src/tablet-activities.ts`, `src/distance.ts`, `src/delivery.ts`, `src/workshops.ts`: 10개 2D 실험
- `src/trial-records.ts`, `src/final-mission.ts`: 그림 기록과 최종 기본·선택 복구
- `src/domain.ts`, `src/storage.ts`: 과학 규칙·진행·증거·저장
- `src/art.ts`, `src/styles.css`, `src/adventure.css`, `src/tablet.css`, `src/ending.css`: 2D 그래픽과 UI
- `public/assets/`: 제공 에셋의 런타임용 복사본
- `tests/`: 진행·물리·저장 실패 검증
- [설계 문서](docs/README.md), [구현·검증 기록](docs/IMPLEMENTATION.md)

데스크톱 브라우저에서 전체 완주와 주요 화면 크기를 검증했다. 실제 태블릿·전자칠판 입력과 수업 적용 검증은 별도로 필요하다.
