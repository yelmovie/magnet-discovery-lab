# PRD — 밀고 당기는 도시

- 문서 버전: 1.0
- 제품명: **밀고 당기는 도시**
- 영문 작업명: **Push Pull City**
- 대상: 초등학교 4학년
- 교과/학기: 과학 4학년 1학기 「자석의 이용」
- 구조: **5 Stages / 10 Pages**
- 권장 플레이 시간: 30~40분
- 플랫폼: 태블릿 우선 웹앱/PWA, 데스크톱 호환
- Science World 분류: 물질·에너지
- Science World Topic ID: `topic-09-magnet`
- GitHub Repository: `push-pull-city`
- GitHub Description: `An interactive Grade 4 science game where students investigate magnetic forces, infer magnetic poles, control objects without touching them, and design useful magnetic devices through 2D, 2.5D, and 3D simulations.`

## 1. 제품 한 줄 정의

학생이 자석의 성질을 문제로 맞히는 대신 **예상 → 직접 조작 → 현상 관찰 → 비교·추론 → 적용 → 설계·시험**을 반복하며 도시의 자석 장치를 복구하는 4학년 수행형 과학 게임.

## 2. 문제 정의

「자석의 이용」은 실제 자석을 가까이하고, 극을 비교하고, 생활 속 장치를 조사·설계하는 조작 활동이 중심이다. 따라서 활동지, OX, 객관식, 단순 분류를 화면으로 옮기는 방식만으로는 태블릿을 사용할 이유가 약하다.

본 제품은 실물 자석 실험을 대체하지 않고 다음을 디지털로 확장한다.

1. 같은 상황을 극·거리·재료·배치 조건만 바꾸어 빠르게 반복한다.
2. 보이지 않는 힘을 '정답 그림'이 아니라 물체의 실제 움직임으로 관찰한다.
3. 자석을 회전·이동·배치하고 그 결과를 즉시 비교한다.
4. 앞 화면에서 얻은 관찰 기록을 뒤 화면의 추론과 설계에 재사용한다.
5. 실물 수업에서 준비하기 어려운 대형 장치, 수조, 원격 카트, 3D 조립 장치를 안전하게 시험한다.
6. 마지막에는 장치를 그리는 데서 끝내지 않고 **설계 → TEST → 근거 확인 → 필요 시 수정**까지 수행한다.

## 3. 적용 성취기준

2022 개정 교육과정 3~4학년 과학 「자석의 이용」의 직접 성취기준은 다음 3개다.

- **[4과09-01]** 자석과 여러 가지 물체를 가까이했을 때 나타나는 현상을 관찰하고, 자석과 자석에 붙는 물체 사이에 작용하는 힘의 특징을 말할 수 있다.
- **[4과09-02]** 자석과 자석을 가까이했을 때 나타나는 현상을 관찰하여 그 특징을 자석의 극과 관련지어 설명할 수 있다.
- **[4과09-03]** 자석을 이용하여 일상생활을 편리하게 하는 장치를 설계할 수 있다.

### 보조 연계 가능 성취기준

필수 평가 기준은 아니며 결과 기록·설명 단계에서만 보조적으로 연결한다.

- **[4국03-02]** 절차와 결과가 드러나게 정확한 표현으로 보고하는 글을 쓴다.
- **[4국03-03]** 대상에 대한 자신의 의견과 그렇게 생각한 이유가 드러나게 글을 쓴다.
- **[4사09-01]** 생활 주변에서 찾을 수 있는 여러 가지 문제를 파악하고, 그 문제를 합리적으로 해결하는 능력을 기른다.
- **[4미02-01]** 관찰과 상상으로 아이디어를 떠올려 표현 주제를 구체화할 수 있다.
- **[4미02-05]** 미술과 타 교과를 관련지어 주제를 표현하는데 흥미를 가질 수 있다.

## 4. 4학년 수준 경계

### 반드시 포함
- 관찰 결과를 근거로 다음 행동을 결정한다.
- 한 화면에서 최소 두 조건을 비교하거나 한 번 이상 재조작한다.
- 극 판별에서 결과를 보고 추론한다.
- 장치 설계에서 자석의 위치 또는 극 방향이 기능에 영향을 주게 한다.
- 앞 단계의 지식을 후반 문제에 다시 적용한다.

### 핵심 플레이로 사용하지 않음
- OX만으로 Stage 완료
- 3지선다 반복
- 붙는 물체/안 붙는 물체를 두 상자에 한 번 분류하고 종료
- N극/S극 단순 짝맞추기
- 그림 속 자석 위치 클릭만으로 완료
- 장치 설계를 그림판이나 텍스트 입력만으로 종료
- 학습과 무관한 폭탄·랜덤점수 시스템을 핵심 보상으로 사용

### 다루지 않는 범위
- 자기장·자기력선의 정식 개념
- 자기력의 정량 공식
- 자속, 전자기 유도
- 자석 세기와 거리의 수학적 관계
- 실제 제품의 정확한 공학 성능 예측
- 5~6학년 전자석 개념

내부 시뮬레이션은 교육용 규칙을 사용할 수 있으나 학생 화면에는 정밀한 실제 자력 측정처럼 제시하지 않는다.

## 5. 학습 목표

학생은 플레이 후 다음을 수행할 수 있어야 한다.

1. 여러 물체에 자석을 가까이하여 반응을 관찰하고 자석에 붙는 물체의 특징을 설명한다.
2. 자석과 자석에 붙는 물체 사이의 힘이 직접 닿지 않아도 작용하는 상황을 관찰한다.
3. 같은 극과 다른 극을 가까이했을 때 나타나는 밀어냄·끌어당김을 구분한다.
4. 기준 자석과 관찰 결과를 이용하여 표시가 없는 자석의 극을 추론한다.
5. 자석의 끌어당김·밀어냄을 이용해 물체를 직접 만지지 않고 움직인다.
6. 생활 속 자석 장치에서 자석이 있는 위치와 편리한 점을 연결한다.
7. 생활의 불편을 해결하기 위해 자석이 필요한 위치와 방향을 계획한다.
8. 만든 장치를 시험하고, 결과를 근거로 성공 이유를 설명하거나 필요 시 수정한다.

## 6. 핵심 설계 원칙

### 6.1 선택보다 조작
정답 버튼을 누르기 전에 학생이 먼저 자석을 움직여 현상을 만들어야 한다.

### 6.2 예상-결과 비교
가능한 화면에서는 실험 전 짧은 예상과 실험 후 실제 결과를 함께 남긴다. 틀림은 즉시 소거하지 않고 관찰 기록으로 활용한다.

### 6.3 앞 화면의 데이터 재사용
Stage 1의 생활 속 자석 사례, Stage 2의 관찰 기록, Stage 3의 극 판별 기록이 Stage 5 설계 도움말과 근거 카드로 다시 등장한다.

### 6.4 읽기는 간결하게, 사고는 낮추지 않기
한 번에 긴 설명을 읽게 하지 않는다. 대신 비교·추론·계획·수정은 유지한다.

### 6.5 3D는 학습 가치가 있을 때만
전체를 3D로 만들지 않는다. 공간 회전·입체 조립·자석 배치가 학습에 직접 필요한 **Page 01, 06, 09, 10**만 핵심 3D로 구성한다.

### 6.6 정밀 물리처럼 보이지 않기
거리와 힘은 `가까움 / 조금 떨어짐 / 멀리`와 같은 정성적 관찰로 표현한다. cm 단위와 정밀 힘 수치를 학습 정답으로 요구하지 않는다.

## 7. 세계관

Science World의 물질·에너지 포털을 통과하면 자석 기술로 움직이는 **밀고 당기는 도시**에 도착한다.

도시의 자석 제어 코어가 불안정해지면서 다음 문제가 동시에 발생했다.

- 생활 장치의 자석 위치 정보가 손실됨
- 재료 분류 시스템 오작동
- 자석 극 표시가 사라짐
- 부유 발전기 정지
- 수조 청소 장치와 무접촉 카트 고장
- 시민 발명 공방의 시험 시스템 중단

학생은 **도시 복구 엔지니어**가 되어 5개 구역을 순서대로 복구한다. Stage 완료 때마다 `자기 코어 조각` 1개를 얻고, 5개를 모으면 최종 `도시 자기 코어`가 복구된다.

## 9. Stage 1 — 생활 자석 조사국

### Page 01 — 도시 물건 해부실 (3D)
생활 속 물건에서 자석이 들어간 위치와 그 위치가 기능과 어떤 관계가 있는지 조사한다.

대상 예시:
- 자석 책갈피
- 스마트 기기 덮개
- 자석식 보관함/정리함
- 자석 여밈 장치

플레이:
1. 물건 하나를 선택한다.
2. 한 손가락으로 회전하고 핀치로 확대한다.
3. 실제 사용 동작을 실행한다: 열기/닫기/붙이기/떼기.
4. `내부 보기`를 사용하면 외장이 반투명해진다.
5. 학생이 자석이 있을 것으로 예상되는 두 위치에 마커를 놓는다.
6. 장치를 다시 작동시켜 두 위치가 마주 보는지 확인한다.
7. 최소 2개 물건을 조사해야 완료.

3D 이유: 평면 사진에서 보이지 않는 앞/뒤·안/밖·마주 보는 면 관계를 직접 회전해 확인한다.

### Page 02 — 자석 ON/OFF 비교실
Page 01에서 조사한 장치를 자석이 있을 때와 없을 때 각각 작동시켜 기능 변화를 비교한다.

필수 흐름:
`ON 상태 작동 → OFF 상태 작동 → 차이 관찰 → 자석의 역할 → 편리한 점 연결`

두 상태를 모두 실행하기 전에는 제출할 수 없다.

## 10. Stage 2 — 힘 실험 연구소

### Page 03 — 재료 반응 실험대
철 클립, 철못, 철제 뚜껑, 알루미늄 물체, 플라스틱, 나무, 고무, 유리 등을 직접 시험한다.

필수 조건:
- 최소 6개 실험
- 철 물체 2개 이상
- 비자성 비금속 2개 이상
- 알루미늄 등 `금속처럼 보이지만 붙지 않는 예시` 1개 이상
- 예측 → 자석 접근 → 결과 관찰 → 기록 → 공통점 추론

`금속이면 모두 자석에 붙는다`는 오개념이 게임 규칙에 들어가지 않도록 물체별 `magnetic` 데이터를 사용한다.

### Page 04 — 거리와 힘 실험대
같은 철 물체를 두고 거리와 사이의 얇은 판 조건을 바꾸어 반복한다.

필수 조작:
- `가까움 / 조금 떨어짐 / 멀리` 거리 구간
- 종이·얇은 플라스틱·얇은 유리 등 비자성 판 삽입
- 같은 조건에서 판 유무 비교
- 마지막에 칸막이 너머 물체 이동 적용 미션

거리와 힘의 정량 법칙을 가르치는 화면이 아니므로 정확한 cm·힘 수치를 표시하지 않는다.

## 11. Stage 3 — 극성 복원 센터

### Page 05 — 극 추리 실험실
N/S가 표시된 기준 자석 하나와 극 표시가 가려진 미지 자석 4개를 제공한다.

학생은:
1. 기준 자석을 뒤집어 사용할 극을 정한다.
2. 미지 자석의 한쪽 끝에 가까이한다.
3. 끌어당김/밀어냄을 관찰한다.
4. 실험 기록을 바탕으로 양끝의 N/S를 추론한다.

적은 실험 횟수는 보너스 조건일 뿐 학습 실패 조건은 아니다.

### Page 06 — 부유 고리 발전기 (3D)
고리자석 4~5개를 들어 올리고 180° 뒤집어 세로 봉에 넣는다.

- 마주 보는 같은 극 → 간격을 둔 `부유` 상태
- 마주 보는 다른 극 → `붙음` 상태

정밀 자기력 시뮬레이션이 아니라 극 조합에 따른 교육용 상태 애니메이션을 사용한다.

3D 이유: 고리의 위·아래 면과 서로 마주 보는 극의 공간 관계를 회전·삽입 과정으로 직접 이해한다.

## 12. Stage 4 — 원격 제어 구역

### Page 07 — 아쿠아 청소 구조실
수조 바깥쪽 자석만 손가락으로 움직여 안쪽 청소 패드를 조종한다.

- 패드가 지나간 영역만 얼룩이 지워짐
- 너무 멀어지거나 지나치게 급하게 움직이면 연결이 끊길 수 있음
- 끊긴 뒤 다시 가까이 가져가 재연결 가능
- 결과: 청소율, 분리 횟수, 경로 길이

핵심은 직접 닿지 않아도 자석 사이 상호작용을 이용할 수 있다는 점이다.

### Page 08 — 무접촉 카트 제어실
카트 자체는 터치할 수 없다.

- 조종 자석을 카트 앞/뒤/옆에 배치
- 자석을 뒤집어 밀기/끌기 전환
- 철제 장애물을 먼저 이동해 길 확보
- 후반 구간은 2~3단계 행동 순서를 스스로 계획
- 하나의 고정 클릭 순서가 아니라 여러 타당한 해결 경로 허용

완전 3D 대신 아이소메트릭 2.5D를 사용해 경로와 극 관계를 한눈에 읽게 한다.

## 13. Stage 5 — 시민 발명 공방

### Page 09 — 발명 설계실 (3D)
생활의 불편을 해결하는 문제 카드를 고른다.

예:
- 자꾸 열리는 보관함
- 철로 된 작은 도구 정리
- 손이 닿기 어려운 곳의 가벼운 철제 물체 이동
- 두 부분을 쉽게 붙였다 떼는 장치

제공 부품:
`케이스 / 뚜껑 / 손잡이 / 철판 / 바퀴 / 막대 / 끈 / 스펀지 / 자석 모듈`

학생은:
1. 사용할 자석 성질을 계획한다.
2. 3D 작업대에 최대 8개 부품을 배치한다.
3. 스냅 포인트에 자석을 설치한다.
4. 자석 방향을 180° 뒤집거나 부품을 90° 회전한다.
5. `이 자석이 무엇을 끌거나/밀어야 하는가` 근거를 지정한다.

완전 자유 CAD가 아니라 4학년이 기능을 판단할 수 있는 제한형 모듈 조립으로 한다.

### Page 10 — 작동 시험실 (3D)
Page 09의 설계를 동일한 위치·회전값으로 그대로 불러온다.

TEST:
1. 문제 카드별 시험 시나리오 실행
2. 자석 위치, 극 관계, 대상 재료, 정성적 거리 조건 검사
3. 실제 작동 애니메이션
4. 성공하면 학생이 힘이 작용한 관계를 표시해 근거 확인
5. 실패하면 작동하지 않은 관계만 알려 주고 정답 배치는 공개하지 않음
6. Page 09로 돌아가 수정 후 재시험 가능

**첫 설계를 일부러 실패시키지 않는다.** 첫 TEST에 성공해도 근거 설명을 완료하면 통과한다.

최종 산출: `나의 자석 장치 설계 카드`
- 작품명
- 해결하려는 불편
- 사용한 자석의 성질
- 자석 위치 및 N/S 표시
- 작동 모습 캡처
- 시험 결과
- 수정한 점(수정한 경우)
- 성공 근거

## 15. 3D 적용 원칙

## 16. 적응형 피드백과 힌트

1. 관찰 질문: “두 물체는 실제로 어느 쪽으로 움직였지?”
2. 조작 부위 강조: 관련 자석 또는 장치만 부드럽게 강조
3. 부분 시범: 첫 행동만 짧게 보여 주기
4. 직접 안내: 여러 번 막힌 경우에만 한 단계 행동 제공

오개념 후보:
- 금속처럼 보이면 모두 붙는다고 반복 예측
- 같은 극/다른 극 규칙 혼동
- 실제 실험 없이 색만 보고 극 선택
- 설계에서 자석이 작동 대상과 연결되지 않음

오개념이 감지되면 다음 Stage 전 20~30초의 짧은 **조작형 재실험 카드**를 제공한다.

## 17. 평가 및 보상

각 Stage 최대 3별.

- **1별:** 필수 핵심 미션 완료

## 20. 벤치마킹 원칙

첨부 자료에서는 다음 **학습 의도와 활동 구조만** 참고한다.

- 생활 속 자석: 물건 속 자석 위치와 편리한 점 연결
- 수조 청소: 직접 손대지 않고 자석으로 반대쪽 청소 도구 이동
- 자석 자동차: 판을 사이에 두고 자석으로 자동차 이동
- 장치 설계 활동: 생활의 불편 → 설계 → 자석 위치/N/S·힘 표시 → 개선점
- 골든벨/폭탄형 정리 게임: 단원 핵심 개념과 오개념 후보 수집

원문 문항, 활동지 레이아웃, PPT 게임 룰, 캐릭터/미술, 점수·폭탄 카드, 자동차 미로 도안은 복제하지 않는다.
