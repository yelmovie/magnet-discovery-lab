# 교사용 안내 · 밀고 당기는 도시 (05 자석)

## 1. 한 줄 소개

밀이·당이와 도시의 다섯 구역을 다니며 자석 장치를 직접 고치고, 마지막에 주민의 불편을 해결하는 발명품을 설계하는 자석 탐구 웹게임입니다.

## 2. 대상

| 항목 | 내용 |
|---|---|
| 학년·학기 | 초등 4학년. 학기는 확인 필요 |
| 과목 | 과학 |
| 단원 | 「자석의 이용」(2022 개정 과학과 교육과정 초등 3~4학년군). 교과서 단원 번호는 확인 필요 |
| 성취기준 | [4과09-01] 자석과 여러 가지 물체를 가까이했을 때 나타나는 현상을 관찰하고, 자석과 자석에 붙는 물체 사이에 작용하는 힘의 특징을 말할 수 있다. |
| | [4과09-02] 자석과 자석을 가까이했을 때 나타나는 현상을 관찰하여 그 특징을 자석의 극과 관련지어 설명할 수 있다. |
| | [4과09-03] 자석을 이용하여 일상생활을 편리하게 하는 장치를 설계할 수 있다. |

활동별 학습 목표는 앱의 설정 › 교사용 가이드에 「교사 검수 전」으로 표시돼 있습니다. 교사 검수는 아직 받지 않았습니다.

## 3. 준비

- 기기: 태블릿(가로 화면)을 기본으로 하고, 전자칠판과 PC에서도 열립니다. 개인 또는 두 학생이 한 태블릿을 함께 씁니다.
- 소리: 배경 음악, 효과음, 목소리가 있습니다. 설정에서 각각 끌 수 있습니다.
- 예상 시간: 설계 목표는 35~50분입니다. 실제 수업 시간은 측정하지 않았습니다(확인 필요). 제한시간은 없고, 진행은 저장되어 다음 시간에 이어 할 수 있습니다.

## 4. 차시 흐름

시작 화면 → 인트로 영상 → 도시 지도 → 구역별 활동 → 구역마다 12초 개념 영상 → 마지막 복구 → 엔딩 영상 → 인증서 순서입니다. 지도에서는 불빛이 켜진 건물로 들어갑니다. 지도에는 악당이 나오고, 세 번 맞히면 물리쳐 성취 카드를 받습니다(카드 6장).

| 구역 | 활동 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|---|
| 1 생활 자석 조사국 | 2 빠른 우편함 수리 | 부품을 조립하고 덮개를 닫은 뒤 흔들어 봅니다 | 자석이 철판을 당겨 덮개를 붙잡습니다 |
| 2 힘 실험 연구소 | 3 철 부품 분류 | 자석을 대 보고 붙는 물건은 위 수리함, 붙지 않는 물건은 아래 분류함에 옮깁니다 | 금속이라고 모두 자석에 붙지는 않습니다 |
| | 4 철 열쇠 꺼내기 | 자석으로 틈 속 철 열쇠를 끌어 꺼냅니다 | 자석은 닿기 전부터 철을 끌어당깁니다 |
| 3 극성 복원 센터 | 5 지워진 극 표시 복원 | 가려진 자석에 기준 자석을 대 보고, 밀림과 당김을 보고 극 스티커를 붙인 뒤 두 문을 엽니다 | 같은 극은 밀고 다른 극은 당깁니다 |
| | 6 고리자석 승강 발판 | 고리를 뒤집어 띄우거나 붙여 발판을 올리고 내립니다 | 마주 보는 극에 따라 뜨거나 붙습니다 |
| 4 원격 제어 구역 | 7 수조 청소 | 유리 밖 손잡이의 자석으로 물속 패드를 움직여 세 곳을 닦습니다 | 자석의 힘은 유리를 사이에 두고도 작용합니다 |
| | 8 자석 택배 | 3D 길을 걸어 자석으로 수레를 중간 깃발과 유리벽 너머 깃발까지 보냅니다. 3D가 안 되는 기기에서는 2D 실험대로 바뀝니다 | 극을 바꾸어 밀기와 당기기로 물체를 옮깁니다 |
| 5 시민 발명 공방 | 9 발명 설계 | 주민 불편을 고르고 쓸 자석의 성질(두 개까지)을 골라 설계 스케치를 합니다 | 자석의 성질을 생활에 이용합니다 |
| | 10 발표회 | 발명품 이름과 소개 글을 쓰고 전시합니다. 친구 의견은 선택입니다 | 쓴 성질을 설명하고 더 알아볼 점을 찾습니다 |

활동 1(우편함 직접 조립)은 지금 열리지 않고, 1번이나 2번으로 들어가면 모두 2번으로 갑니다.

## 5. 정답과 판정 기준

| 활동 | 정답 또는 통과 조건 |
|---|---|
| 2 | 부품을 점선 자리에 모두 놓고, 덮개를 닫은 뒤 흔들어도 닫혀 있으면 통과합니다 |
| 3 | 자석에 붙는 것은 철 클립, 철못, 철 너트이고 위 수리함으로 옮깁니다. 알루미늄 포일, 나무 조각, 플라스틱 조각은 붙지 않고 아래 분류함입니다. 여섯 개를 모두 나누면 통과합니다. 관찰 확인 문제의 정답은 「철로 된 물건」입니다 |
| 4 | 자석에 붙은 철 열쇠를 왼쪽으로 꺼내면 통과합니다. 발견 정리 문제의 정답은 「닿기 전부터 자석 쪽으로 끌려와」입니다 |
| 5 | 두 반응에 맞게 양쪽 끝에 극 스티커를 붙이고, 첫 문은 같은 극으로 밀어서, 두 번째 문은 다른 극으로 당겨서 열면 통과합니다. 첫 판의 가린 자석 끝은 S극입니다 |
| 6 | 고리를 뒤집어 같은 극이 마주 보면 뜨고 다른 극이 마주 보면 붙습니다. 발판을 올리고 내려 두 친구를 건네면 통과합니다. 발견 정리 문제의 정답은 「마주 보는 같은 극끼리 밀어내서」입니다 |
| 7 | 세 곳을 모두 닦으면 통과합니다. 관찰 확인 문제의 정답은 「유리 밖 자석을 따라 패드가 움직였어」입니다 |
| 8 | 수레를 중간 깃발에 멈춘 뒤 유리벽 너머 깃발 칸에 멈추면 통과합니다. 발견 정리 문제의 정답은 「자석이 카트를 밀거나 당겨서」입니다 |
| 9·10 | 맞고 틀림이 없습니다. 불편 고르기, 성질 고르기(두 개까지), 이름 짓기, 소개 글 열 글자 이상, 전시관에 걸기를 하면 진행됩니다 |

홀수 화면은 실험만 하고, 짝수 화면은 실험 뒤 발견 정리 문제가 하나 나옵니다. 관찰 확인 문제(활동 3·7)는 실험을 자동 시연으로 관찰했을 때만 나옵니다.

## 6. 수업 팁

- 자주 막히는 곳: 활동 5에서 스티커를 붙이기 전에 기준 자석을 먼저 가까이 대야 합니다. 활동 8에서는 수레가 깃발 칸 밖에 멈추면 「자석 들기」를 눌러 조금 더 옮겨야 합니다.
- 되묻기 좋은 질문
  - 금속이면 모두 자석에 붙을까? (활동 3)
  - 고리를 뒤집으면 마주 보는 면이 어떻게 달라졌니? (활동 6)
  - 유리가 가로막고 있는데 왜 패드가 움직였을까? (활동 7)
- 활용: 두 학생이 한 태블릿에서 역할을 나누거나, 전자칠판에 띄워 전체 수업에서 예상과 결과를 비교할 수 있습니다. 활동 10의 전시관은 전자칠판에 띄워 함께 볼 수 있습니다.
- 교사용: 설정의 「교사용 · 모든 스테이지 열기」를 누르면 활동 10개와 마지막 복구가 모두 열립니다. 학생 기록은 바뀌지 않습니다.

## 7. 저장과 다시 하기

- 진행과 연구 기록은 이 기기의 브라우저(IndexedDB)에 자동 저장됩니다. 다른 기기로 옮겨지지 않습니다.
- 처음부터 다시 하려면 설정의 「탐험 기록 초기화」를 누르고 「기록 지우기」를 고릅니다. 소리 설정은 남습니다.
- 교사용으로 열었을 때는 「교사용 기록 지우기」가 나오고, 학생 기록은 지워지지 않습니다.
