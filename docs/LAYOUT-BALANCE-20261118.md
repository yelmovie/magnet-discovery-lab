## 중복 조작 버튼 전수 점검

화면마다 보이는 버튼을 측정 스크립트로 모두 뽑아(`before/measure.json`의 `buttons`) 같은 일을 하는 것을 찾았다.

| 화면 | 겹치는 버튼 | 처리 |
|---|---|---|
| 탐험 보고서 | 아래 「도시로 돌아가기」 = 왼쪽 위 HUD 홈(「지도로 가요」). 둘 다 `go('city')` | 「도시로 돌아가기」 숨김(`fit-report.css`). 주 버튼 「발견 정리 시작」만 남음 |
| 인증서 | 「도시 둘러보기」 = HUD 홈(「지도로 가요」). 둘 다 `go('city')` | 「도시 둘러보기」 숨김(`fit-report.css`). 「인증서 인쇄」(주)·「엔딩 다시 보기」 남음 |
| 타이틀(처음) | 눌리지 않는 「이어 하기」가 주 버튼 옆에 같은 크기 | 저장이 없으면 그리지 않음(`quest-ui.ts`). 저장이 있으면 「시작하기」(새로)·「이어 하기」(주) 그대로 |

그대로 둔 것과 이유:

- 활동 화면 HUD 홈·뒤로: 같은 곳(지도)으로 가는 경우가 많지만 공통 기준이 왼쪽 위 홈·뒤로를 모든 화면 같은 자리로 지키라고 해서 유지.
- 지도 「다음 목적지 자동으로 들어가기」 + 건물 직접 누르기: 3초 규칙 문서에서 다음 목적지 버튼을 지도의 3초 목표(주 버튼)로 정했다. 유지.
- 지도 「손으로 지도 이동」: 지도를 끌면 같은 상태가 되지만, 끈 뒤 다시 누르면 밀이를 따라가는 화면으로 돌아오는 유일한 버튼이고 악당 공격 버튼 위치가 이 버튼에 붙어 있다(`map-encounters.js` `dockMapAttack`). 유지, 제안만.
- 활동 3·4·7·9·10 오른쪽 위 보상 도구 버튼(예: 「자석 수리 키트」): 누르면 그 도구의 쓰임을 알리는 토스트. 「자꾸 · 힌트」와 내용이 다르고(보상 이야기), 활동 5·6에서는 관찰 렌즈를 켜는 실제 기능. 유지, 제안만.
- 활동 6 「1번/2번 고리 뒤집기」: 고리를 끄는 것과 다른 동작(극 뒤집기). 유지.
- 공방 스케치 「그림으로 다운로드」와 전시 단계 「그림으로 다운로드」: 다른 단계에 하나씩. 유지.

합계: 없앤 중복 버튼 3개(보고서 1, 인증서 1, 타이틀 1).

## 제안 (이번에 하지 않음)

1. **실험대 기구 확대**: 캔버스·히트 버튼·안내를 한 묶음(`.bench-zoom` 래퍼)으로 넣고 매트 중심 기준으로 약 1.15배 확대하면 1280×800에서 기구 판 높이 48→55%가 된다. 드래그 좌표 계산(`manipulation.ts`가 `.play-board` 기준)과 힌트 강조·안내 말풍선 위치를 같이 옮겨야 해서 별도 작업으로 남긴다. 높이 70%는 1280×720 캔버스의 매트 위치(y 226~610)를 바꾸지 않는 한 구조상 어렵다.
2. 지도 「손으로 지도 이동」: 지도를 끌면 자동으로 켜지는 상태 표시로 바꾸고, 「밀이 따라가기」 한 가지 역할만 남기는 안.
3. 보상 도구 버튼: 활동 5·6처럼 실제 기능이 없는 곳은 처음 한 번만 보여 주고 접는 안.
