- 캔버스(Three) 안 글은 재지 못했다.
- 기존 `scripts/layout-check.cjs`는 저장 데이터를 넣는 단계에서 멈춰(2026-10-25 기준 스크립트, 이번 변경과 무관) 돌리지 못했다. 대신 바뀐 화면을 스크린샷으로 확인했다.
