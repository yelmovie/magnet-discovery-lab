# 인트로·엔딩 영상 적용 · 2026-11-01

사용자가 프로젝트 최상위에 넣어 준 `intro.mp4`·`final.mp4`를 정리하고, 효과·효과음을 더해 게임에 연결했다.

## 다른 프로젝트에서 가져온 규칙

- 자막은 영상에 굽지 않고 화면 글자(DOM)로 시간에 맞춰 얹는다. 4개 프로젝트 모두 같다. 전자칠판에서 선명하고, 문구를 고쳐도 다시 렌더하지 않는다.
- 건너뛰기는 처음부터 항상 누를 수 있다. Esc도 같다.
- 무음 영상에는 게임 배경음을 깐다: 인트로는 메인 테마, 엔딩은 파이널 테마.
- 인트로는 처음 시작할 때만, 엔딩은 마지막 복구를 마친 뒤에 나온다. 설정에서 다시 볼 수 있고 엔딩은 완료 전 잠금.
- 생명 시계 연구실의 연출(장소 태그, 구역 도장이 차례로 켜짐, 마지막 타이틀 카드, 건너뛰기 → 카드로 이동, 8초 로딩 실패 시 대체 화면)을 이 프로젝트 색·말투로 옮겼다.

## 편집 — 영상에 구운 것 (글자 없음)

- 원본 끝의 검은 화면 페이드를 잘라 내고 마지막 장면을 멈춘 채 천천히 확대한다. 인트로는 15.27초 장면을 2.2초, 엔딩은 12.27초 장면을 5.1초 멈춘다. 엔딩 원본은 12.3초부터 초점이 크게 번지는 구간이 있어 그 앞의 선명한 장면을 썼다.
- 측정값: 컷 인트로 5.2초·11.72초, 엔딩 5.3초·10.733초 / 철 클립 (790,602)→(793,607) / 수레 도착 4.0초 (812,468) / 메달 중심 (646,363). 결과 각 3.5MB, 1280×720 30fps, 오디오 최고 -6 dBFS.
- 1280×720으로 맞추고 따뜻한 색 보정·약한 비네트, 시작 0.5초 페이드 인.
- SVG 프레임을 sharp로 그려 FFmpeg로 합성: 먼지 입자, 컷 전환 빛, 연구소 단서(철 클립) 표시 고리와 자기력 물결, 공방 빛 줄기, 수레 도착 반짝임, 수조 거품, 메달 광선·반짝임, 색종이. Remotion은 쓰지 않았다.
- 효과음: 컷 전환 바람 소리, 단서 발견 딩, 수레 도착, 축하 팡파르 등. 게임 효과음 설정이 꺼져 있으면 영상도 소리 없이 재생한다.

## 화면 글자 — `src/story-video.ts`

말투는 게임 본편처럼 밀이·당이의 반말이다.

| 영상 | 왼쪽 위 장소 태그 | 자막 흐름 | 마지막 카드 |
|---|---|---|---|
| 인트로 17.5초 | 긴급 수리 의뢰·우편국 골목 → 단서를 찾아라·힘 실험 연구소 → 나만의 발명·시민 발명 공방 | 고장 발견 → 철 클립만 붙는 단서 → 직접 실험하면 고칠 수 있다 → 마지막엔 네 발명품 | 수리 대장은 바로 너! · 보상 3개(구역 도구·도시 축제·연구원 인증서) · 밀이·당이와 출발! |
| 엔딩 17.4초 | 발명품 시험 운행 → 다시 움직이는 도시 → 도시 축제·중앙 광장 | 내 발명품 성공 → 수조·수레·우편함 회복 → 다섯 구역 복구, 주인공은 너 | 도시 복구 100% 도장 · 자석 도시 복구 연구원 탄생! · 인증서 받으러 가기 |

- 엔딩에서는 다섯 구역 도장(생활·재료·극·원격·발명)이 회복 장면에 맞춰 하나씩 켜지고, 팡파르 때 모두 빛난다. 마지막 카드가 뜨면 4:3 화면에서도 메달이 보이게 도장 줄은 숨긴다.
- 연구소 장면 자막 2줄은 왼쪽에 붙여 철 클립 단서 표시를 가리지 않는다(자막 데이터의 `left`).
- 건너뛰기 → 마지막 카드로 이동(카드의 동기·보상 문구는 꼭 보이게). 설정에서 다시 볼 때는 버튼이 '닫기'로 바뀌고 바로 돌아간다.
- 동작 줄이기 설정이면 자동 재생하지 않고 '영상 보기' 버튼을 띄운다. 자동 재생이 막히면 소리를 끄고 다시 시도하고, 그래도 안 되면 버튼을 띄운다.
- 8초 안에 재생이 시작되지 않거나 파일 오류면 마지막 장면 그림 + 마지막 카드로 넘어간다.
- 닫을 때 `pause → src 제거 → load()`, `#app` inert 원복, 포커스 반환.

## 흐름

- 시작하기(처음) → 인트로 → 카드 버튼 → 도시. 이어하기에서는 나오지 않는다.
- 마지막 복구 → `ending` 화면 = 엔딩 영상(파이널 테마 처음부터) → 카드 버튼 → 인증서.
- 설정: '이 탐험을 하는 이유 다시 보기' = 인트로, '도시 축제 다시 보기' = 엔딩(완료 후).
- 이전의 이야기 모달(`openStory`)과 24초 2D 엔딩 슬라이드는 영상으로 바뀌어 코드에서 뺐다.
- 회귀 스크립트(`scripts/browser-regression.cjs`, `playful-regression.cjs`)는 건너뛰기 → 카드 버튼으로 영상을 지나가게 고쳤다.
