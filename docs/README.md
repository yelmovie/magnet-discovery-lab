## 이번 대화에서 확정한 기준

- 프로젝트는 **밀고 당기는 도시**이며 자연 배경 테마가 아니다.
- 메인 다음 스테이지 선택은 **캐릭터가 돌아다니는 2.5D 픽셀아트 RPG 도시 탐험**이다.
- **도시 탐험 화면에만** 비스듬한 시점과 픽셀아트를 적용한다.
- 메인, 5장·10개 활동, 결과와 엔딩은 기존 샘플 분위기의 **2D**로 구현한다.
- 폴더의 샘플은 색감·오브젝트·캐릭터의 참고 자료다. 글자와 버튼이 구워진 화면 이미지를 게임 UI로 사용하지 않는다.
- Quest → Evidence → World Change → Final Report → Final Mission → Final Movie → 인증서 흐름을 유지한다.

## MVP를 위해 이번 설계에서 정한 기본값

사용자가 개별 지정하지 않은 아래 사항은 구현 가능한 범위를 만들기 위한 설계 결정이다.

- 밀이를 이동 캐릭터로, 당이를 광장의 기록 담당으로 사용한다.
- 도시 전체를 자유롭게 걸어 다니되 활동은 1장부터 순서대로 개방한다.
- 지도는 큰 스크롤 월드가 아니라 주요 시설이 한눈에 보이는 한 구역이다.
- 5장 발명은 두 가지 문제 중 하나를 골라 완성한다. 자유 물리 샌드박스는 후속 범위다.
- 엔딩은 별도 AI 영상 제작 없이 20~25초의 2D 장면 애니메이션으로 구현한다.
- 로그인 없는 기기 내 단일 진행 저장을 제공한다. 계정·서버·외부 허브 연동은 후속 범위다.

## 기존 자료와 달라진 부분

| 이전 설계 | MVP 기준 |
|---|---|
| 활동 1·6·9·10에 Three.js 3D | 모두 2D 관찰·배치·뒤집기·시험 |
| 일부 다른 활동도 2.5D | 활동은 정면·측면·평면 시점의 2D |
| 도시 구역을 선택하는 지도 | 캐릭터 이동, NPC 대화, 건물 앞 입장 |
| 자석 ON/OFF | 자석 넣기·빼기 비교 |
| 부유 고리 발전기 | 지지 막대가 있는 고리자석 장치; 발전 원리를 가르치지 않음 |
| 문서 속 당이는 막대자석 | 실제 제공된 당이 시트의 빨강·파랑 U자 형태와 기록 소품 우선 |
| 다양한 발명 부품과 자유 설계 | 두 문제 템플릿, 기능적으로 유효한 배치 선택과 재시험 |

복구율은 **0 → 20 → 40 → 60 → 80 → 95 → 100%**로 통일한다. 5장을 마쳐도 마지막 코어 복구가 남는다.

## 구현 순서와 통과 기준

1. **기반과 1장 연결:** 메인 → 도시 이동 → 입장 → 활동 1·2 → 증거 획득 → 도시 변화 → 새로고침 후 이어하기가 연결된다. 이 단계는 전체 MVP가 아니다.
2. **2·3장:** 재료·거리·극·고리 규칙과 증거 기록이 연결된다.
3. **4·5장:** 청소·카트 조작, 발명 데이터가 시험 결과에 실제로 반영된다.
4. **완주와 품질:** 보고서·최종 미션·엔딩·인증서, 에셋 통일, 태블릿 입력·저장·접근성 검증을 마친다.

위 4단계의 기능 구현과 데스크톱 브라우저 완주 검증을 마쳤다. 실제 태블릿·전자칠판 성능 및 수업 검증은 남아 있다. 계획 문서의 전체 검증 항목이 통과했다는 의미는 아니며, 현재 완료 기준과 차이는 구현·검증 기록에 정리했다.
