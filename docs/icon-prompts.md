# 탐구 도구 아이콘 제작 참고

현재 UI 아이콘은 의미가 명확한 작은 SVG이며, 배경·소품 그림은 `docs/ART-PROMPTS-20261021.md`의 실제 생성본을 사용한다. 아래는 후속 래스터 아이콘을 제작할 때 사용할 미생성 프롬프트다. 현재 앱에 적용됐다고 주장하지 않는다.

공통: cream stone / cobalt / copper의 자석도시, 2.5D 동화 게임 소품, 따뜻한 창문 조명, 정면보다 약간 내려다보는 각도, 실루엣 하나, 512×512 투명 배경, 글자·숫자·UI 프레임 없음. 캐릭터의 얼굴을 소품에 넣지 않는다.

| 도구 | 추가 프롬프트 |
|---|---|
| 자석 수리 키트 | 열린 작은 목제 공구함, 빨강·파랑 막대자석 하나와 작은 철 클립, 크림 손잡이 |
| 힘 관찰 렌즈 | 구리 손잡이 돋보기 하나, 맑은 푸른 유리, 밝은 반사광 |
| 극 표시 스티커 | 빨강과 파랑의 둥근 두 스티커, 겹치지 않는 분리된 실루엣, 문자 없음 |
| 원격 조작 손잡이 | 구리 손잡이와 빨강·파랑 자석이 결합된 실제 도구, 맑은 유리 한 조각 |
| 나의 발명 설계도 | 펼친 크림색 설계 두루마리, 장치의 단순 선 그림, 구리 클립, 읽을 수 있는 글자 없음 |
