# 직접 조작 탐험으로 바꾼 기능향상기

## 달라진 행동

- 목록형 도시를 넓은 돌길·카메라 추적·건물 출입문을 가진 지도 탐험으로 바꿨다.
- 생활 물건 두 종류의 비교 뒤, 철판 자리까지 고치는 새 우편함 문제를 추가했다.
- 재료 카드를 분류하는 대신 자석으로 직접 검사하고 붙은 철 부품을 운반한다.
- 거리 비교 뒤 같은 배치에 얇은 종이만 더한다. 마지막에 다른 위치의 철 열쇠로 적용한다.
- 극의 반응으로 표시를 복원하고, 고리 2개·3개 띄우기와 붙이기를 해결한다.
- 수조는 실제 추종·이탈·재연결, 택배는 극과 앞뒤 위치에 따른 연속 이동으로 바꿨다.
- 발명품을 직접 조립하고 두 조건에서 사용한다. 위치를 고치면 이전 성공을 재사용하지 못하도록 설계 리비전에 묶었다.
- 설계도를 중앙 광장에 장착하고 직접 작동시켜 마지막 복구를 끝낸다.

## 보상과 디자인

수리 키트 → 관찰 렌즈 → 극 스티커 → 원격 손잡이 → 내 설계도가 다음 활동에 이어진다. 입장 전에 보상을 예고하고 완료 후 시설 표시와 움직이는 택배·축제·개인 인증서로 돌려준다. 속도·실수 횟수로 차등 보상하지 않는다.
