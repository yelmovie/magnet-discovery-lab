# 학습 경험 개선 · 2026-10-22

## 적용

- 기존 5구역·10실험과 저장 형식·최초 증거는 유지했다.
- 동물·사람 추종이 아닌 보조 캐릭터 **자꾸**를 자체 SVG 자석 수리 로봇으로 제작했다. 현재 실험·라운드·관찰 여부에 따라 할 일이 달라진다. 눌러 열면 행동 → 관찰 단서 → 추가 단서를 보고 조작할 물체를 강조한다. 완료 안내는 기존 증거 검증을 통과해야 나온다.
- 제목 아래에 구역·실험 번호, 발견 수, 지금 할 행동을 표시했다. 하단에는 힌트·이동 보조·실험 다시 보기·다음 진행을 배치했다.
- 캔버스와 DOM 터치 타깃을 동일한 16:9 실험대에 맞췄다. 거리·경로 표시, 고리의 붙음·뜨는 반응을 보강했다. 고리 이동 중 실험 입력은 잠기고, 모달·백그라운드에서는 애니메이션이 기다린다. 줄인 모션 설정에서는 즉시 결과를 보여 준다.
- 내 실험 다시 보기: 저장된 객체의 처음/결과 위치를 슬라이더로 비교한다. 시간 기록의 동영상 재생이 아닌 위치 비교이며, 번호 범례와 점선으로 구별한다. 실제 관찰 기록은 접어서 본다.
- 각 구역의 두 실험을 마치고 발견을 설명하면 12초 개념 영상을 연다. 전체 시청을 강요하지 않으며, 도구 받기/도시 복귀를 직접 누른다. 연구 가방·최종 보고서에서 다시 볼 수 있다. 오류 시 핵심 개념 텍스트와 진행 버튼이 남는다.
- 팝업 중심 정렬, 내용에 맞는 높이, 본문 20px 이상·보조 16px 이상, 핵심 버튼 48px 이상을 적용했다. 설정은 소리 제어를 두 열로 모으고 긴 가이드는 하나씩 펼친다. 연구 가방·보고서는 구역별 탭으로 긴 카드 목록을 줄였다. 인증서는 1280×800에서 이름 입력까지 한 화면에 들어간다.
- 외부 접속 없이 재생하도록 영상·포스터·자막·효과음을 public에 번들했다. 효과음은 Kenney CC0 8종, 음악은 기존 자체 합성을 유지한다. 영상 중에는 게임 소리를 정지하고 닫으면 복구한다. 출처·배포 라이선스는 assets/CREDITS.md와 public/audio에 있다.

## 개념 영상 컷 시트

공통: 12초, 3컷×4초. 사람·캐릭터가 등장하지 않는 학습용 장치 그림이다. 고정 오버헤드 또는 정면 장치 클로즈업을 사용하고, 물체가 움직여 개념을 보인다. 마지막 약 1초는 결과 배치를 유지한다.

| 구역 | 0–4초 | 4–8초 | 8–12초 |
|---|---|---|---|
| 생활 | 덮개를 열어 자석·철판 발견 | 당기는 힘과 닫힌 덮개 | 자석만 제거해 덮개 열림 비교 |
| 재료·힘 | 철·다른 재료의 서로 다른 반응 | 자석이 가까워지며 철 이동 | 같은 배치에 얇은 종이만 추가 |
| 극 | 같은 극끼리 밀려남 | 다른 극끼리 가까워짐 | 마주 보는 면에 따라 고리 띄우기 |
| 원격 | 유리 밖 자석과 안쪽 철 패드 | 멀어질 때 추종이 끊김 | 앞에서 당기기·뒤에서 밀기 비교 |
| 발명 | 필요한 부품 배치 | 멀리 떨어진 배치의 실패 | 가까이 고친 뒤 두 사용 상황 확인 |

각 컷의 [CAMERA]: 고정 · 흔들림 없음 · 두 물체와 간격을 프레임 안에 유지 · 마지막은 결과 배치에서 멈춤.
[SCENE]: 크림색 실험대, 빨강 N/파랑 S, 철 부품, 개념별 한 동작과 큰 한글 자막. 임의의 자기장·물체 변형은 사용하지 않는다.

재생성: Python에서 `scripts/requirements-media.txt`를 D: 도구 폴더에 설치한 뒤 `python scripts/render-concepts.py`. FFmpeg 실행 파일은 `.tools/python`에서 찾는다. 결과 5편의 MP4 합계는 약 0.89MB이며 manifest에 개별 크기·SHA256을 기록했다.

## 검증

- Vitest **62개 통과**: 기존 55개, 힌트 상태·증거 유효성·기록 불변 6개, 외부 음원 캐시·음소거·영상 중 소리 정지 1개.
- TypeScript와 Vite production build 수행.
- 1280×800, 1024×768, 906×755, 873×580, 1920×1080 CSS 뷰포트에서 실제 모듈을 쓰는 격리된 검증 페이지로 실험 10개의 초기/중간/마지막 **150개 배치**를 실측했다. 표시된 조작 버튼의 화면 이탈·44px 미만 터치 대상·주 실험 타깃끼리 겹침·가로 넘침을 점검했다. 접힌 details 내부의 비표시 버튼은 제외했다. 배치 검사에서 문제 없음.
- 실제 앱에서 덮개 열기·자석 운반·두 장치의 유무 비교·철판 재배치·발견 설명·영상 자동 진입·도구 보상까지 조작했다. 영상은 실제 브라우저에서 1280×720/12초/readyState 4로 재생됐다. 기록 슬라이더의 처음/결과 변경을 확인했다.
- 제목·지도·시설 입구·실험·설정·기록·발견 설명·영상·보상·보고서·최종 장착·엔딩·인증서 화면을 실제 앱에서 열어 확인했다. 인증서의 본문·업적·이름 입력을 확대하고 화면 맞춤을 확인했다. 최종 수료는 교사용 미리보기로 화면만 점검했으며 학생 완료 기록을 강제로 채우지 않았다.
- 고리 반응 중 입력 잠금·실패 배치·다시 조작 가능 상태를 브라우저에서 확인했다. 모든 구역의 전체 완주를 새로 반복한 것은 아니다.
- 실제 태블릿·전자칠판 하드웨어, 교실 스피커 음량·거리 가독성, 학생 소요 시간·학습 효과는 현장 확인이 필요하다.
