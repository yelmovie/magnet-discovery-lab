# 밀고 당기는 도시 · 교사 검수표 (2026-11-21)

- 대상 앱: 05 「밀고 당기는 도시」(자석). 기준 코드: `main` 브랜치 커밋 `21f0b1e`.
- 이 표의 문장은 모두 코드에서 그대로 옮겼다. 문장을 고치지 않았고, HTML 태그만 뺐다. 보기 번호(①②③)와 「정답」 표시만 덧붙였다.
- `${…}`는 화면에서 실제 값(물건 이름, N·S 같은 극 이름, 칸 수)으로 바뀌는 자리다. `<br>`는 같은 칸 안의 줄바꿈이다.
- 출처는 `파일:줄`이다. 여러 문장이 한 줄에 있으면 같은 줄 번호를 쓴다.
- 「검수」 칸에 ☑ 표시를 하고, 고칠 점은 「메모」 칸에 적어 주세요. 메모 칸의 「확인 필요」는 작성자가 과학적으로 틀리거나 헷갈릴 수 있다고 본 곳이다. 문장은 바꾸지 않았다.

## 먼저 읽기: 지금 학생이 실제로 보는 흐름

코드를 따라가 보면 새로 시작한 학생은 아래처럼 진행한다. 표에서 「지금 안 나옴」이라고 적은 문장은 이 흐름에서 화면에 나오지 않는다.

1. **1번 화면은 열리지 않는다.** 1번이나 2번으로 들어가면 모두 2번 「빠른 우편함 수리」로 간다(`src/main.ts:111`). 그래서 구역 1은 2번 한 화면(조립 → 흔들기 → 개념 영상 1)으로 끝나고, 구역 1의 발견 정리 문제는 나오지 않는다(`src/main.ts:243-244, 346-353`).
2. **2~8번은 퍼즐 판이다**(`src/mission-play.ts:41`). 4번은 「철 열쇠 꺼내기」 실험이다(`src/mission-play.ts:69-72`). 이 판에는 거리 눈금 비교와 종이 비교가 없다.
3. **8번은 3D 길이 먼저 열린다**(`src/mission-play.ts:43`). 기기가 3D를 못 그리면 2D 실험대로 바뀐다(`src/run-course.ts:100-103`).
4. **9·10번은 아이디어 공방·발표회다**(`src/idea-model.ts:16`, `src/main.ts:242`). 맞고 틀림이 있는 문제가 없고, 구역 5 발견 정리 문제도 나오지 않는다.
5. **홀수 화면은 실험만, 짝수 화면은 실험 뒤 「발견 정리」 문제 1개**가 나온다(`src/inquiry.ts:141-156`).
6. **실험 중 잘못 조작하면** 퍼즐 판에서는 첫 번째에는 결과 문장만, 두 번째에는 단서 1, 세 번째부터는 단서 2가 붙는다(`src/mission-surface.ts:67-69`, `src/mission-model.ts:43`).
7. **「자동 관찰 확인」 문제(1·3·7번)는** 실험을 자동 시연으로 관찰했을 때만 나온다(`src/inquiry-prompts.ts:45`, `src/mission-surface.ts:62`). 자동 시연은 기본으로 켜져 있다(`src/domain.ts:48` `autoplay: true`).
8. **「장치·개념」 그림 안내와 「꼭 기억해」 문장은 지금 화면에 연결돼 있지 않다.** `visualGuideMarkup`을 부르는 곳이 없고(`src/learning-visuals.ts:54`), 「꼭 기억해」는 9번 화면에서만 보인다(`src/idea-lab.ts:63`). 활동 안내문(`missionGuide`)도 도구 버튼이 없을 때만 나오는데 그 경우가 없다(`src/mission-play.ts:146, 151-152`). 이 문장들은 맨 아래 「부록 A」에 따로 모았다.
