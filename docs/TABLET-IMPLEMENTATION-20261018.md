# 태블릿 탐구 경험 실제 구현 · 2026-10-18

10월 16일 설계·독립 시안을 현재 앱에 연결했다. 서버·계정·새 라이브러리·새 생성 이미지는 추가하지 않았다.

## 실제 변경

- 활동 셸: 질문 하나, 큰 실험대, 현재 안내, 필요할 때 여는 기록 서랍. 기존 우측 설명·보상 패널을 제거했다. 구역 보상과 복구율은 도시에서 확인한다.
- 입력: 드래그·방향키·물체 선택 후 위치 누르기·선택 물체 이동 버튼을 지원한다. 보조 포인터는 진행 중 드래그를 가로채지 않는다. 취소·회전·창 이탈 시 마지막 유효 위치를 남긴다. 서랍이 열리면 배경 입력과 연속 실험을 멈추며 Escape로 닫으면 원래 버튼에 포커스를 돌린다.
- 활동 1~3: 첫 예상 보존, 관찰 뒤 단계 안내, 덮개에 붙은 자석과 몸체의 고정 철판, 같은 흔들기, 여섯 재료를 세 개씩 검사. 맞게 분류한 물체는 자동 확인하고 틀린 분류만 고친다.
- 활동 4: 자유 접근에 따른 클립 반응과 멀리/가까이 자동 기록. 종이 비교에서는 실제 가까운 관찰의 시작 위치를 복원하고 자석을 고정한다. 두 기록의 초기 좌표와 재료를 비교해 종이만 달라졌는지 재검증한다.
- 활동 5~6: 알려진/미지 극 비교와 선택 나침반. 두 고리로 붙음·밀림을 먼저 비교한 뒤 세 고리 주문 하나를 해결하면 기본 완료한다. 남은 주문은 선택이다.
- 활동 7~8: 안팎·유리 단면, 시간 기반 패드 추종과 수레 반응. 수레의 자석과 철 화물은 별도 물체이며, 틀린 극에서도 실제 반대 움직임이 나타난다. 넓은 정차 구역에서 자석을 떼어 멈춘다.
- 활동 9~10: 몸체 준비, 부품 배치 후 필요한 조작 노출, 실제 좌표·극·설계 버전으로 시험. 첫 성공과 자신의 원리 설명만으로 기본 완료할 수 있다. 반대 방향 운반·추가 시험은 선택이며 과거 성공을 새 설계에 재사용하지 않는다.
- 구역 마무리: 자신의 그림으로 질문 하나에 관해 설명했다고 확인한다. 이 자기 확인을 자동 이해도 채점으로 표시하지 않는다.
- 보고서·최종: 대표 발견부터 보여 주고 상세 기록은 펼친다. 기본은 고장 난 한 구간만 직접 작동한다. 기본 고장은 내 발명이며 배송·고리로 바꿀 수 있다. 설계 장착 자체는 성공이 아니다. 나머지는 과거 기록의 읽기 전용 전후 재생이다. 전체 복구 선택 도전과 기본 복구로 돌아가기를 제공한다.
- 로딩: 도시 프로그램·지도 실패 시 해당 파일과 재시도 버튼을 표시한다. 프로그램/지도 준비 전 건물 클릭도 준비 후 이어서 처리한다.

## 기록·저장

`Save.version=2`를 사용한다. IndexedDB 데이터베이스와 저장 키는 그대로다. v1은 검증 후 같은 트랜잭션에서 `v1-backup`을 남기고 `main`을 바꾼다. 실패하면 원본을 보존하고 변환된 메모리 진행을 유지하며 저장 실패를 알린다. 기존 완료·증거·인증서를 새 실험으로 다시 따게 하지 않는다.

실험 스냅샷에는 조건·시작/결과 좌표·모형 버전·설계 버전과 지원 실험의 입력 경로를 저장한다. 입력은 최대 240점, 기록은 64KB 이내다. 일반 기록은 최근 12개로 제한하고 최초 관찰·완료에 쓰인 기록은 별도로 보존한다. 그림과 전후 재생은 이 데이터로 만들며 영상이나 이미지 파일을 브라우저 저장소에 쌓지 않는다. 기존 문장 기록을 새로운 경로로 꾸미지 않는다.

완료 증거는 기존대로 복제해서 보관한다. 관리자 미리보기와 재탐구는 원본 진행을 보존한다. 배경 프레임은 매번 DB에 기록하지 않고 조작 종료·주기적 진행·구간 완료 시 저장한다.

## 파일·초기 전송량

주요 변경은 `src/main.ts`, `adventure.ts`, `tablet-activities.ts`, `distance.ts`, `delivery.ts`, `final-mission.ts`, `trial-records.ts`, `manipulation.ts`, `workshops.ts`, `domain.ts`, `storage.ts`, `tablet.css`다.

원본 캐릭터와 제공 자료는 보존했다. 실행용 캐릭터 두 시트만 최대 표시 크기의 2배인 프레임 304×405로 준비해 무손실 WebP로 저장했다. 두 시트는 1,466,662→551,664 bytes로 줄었다. 지도와 두 캐릭터의 첫 화면 이미지 합계는 1,258,872 bytes다. HTML·JS·CSS gzip 크기를 합친 정적 예산은 약 1.32MB로 1.5MB 목표 이내다. 학교망의 실제 전송 측정값은 아니다. 도시 JS는 gzip 약 335KB이며 도시 진입 때 지연 로드한다.

실행 시 추가 도구는 필요 없다. 선택적인 파생 에셋 재생성만 `scripts/prepare-runtime-art.py`와 Pillow를 사용한다.

- Phaser 도시 청크의 500KB 초과 경고는 유지된다. 지연 로드되며 빌드 오류는 아니다.
