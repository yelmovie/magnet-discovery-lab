# 밀이와 당이의 도시 복구 탐험

사용자가 승인한 실제 앱 고도화. 기존 완료 기록과 인증서는 보존한다. 정답 탭 대신 물체를 조작하고, 관찰 결과를 다음 의뢰에 적용한다.

| 구역 · 성취기준 | 해결할 불편 | 직접 조작과 새로운 조건 | 즉시 결과 · 다음 도구 | 다시 할 이유 |
|---|---|---|---|---|
| 생활 · 4과09-01 | 자꾸 열리는 우편함·책 보관함 | 덮개 열기, 내부 자석 꺼내 관찰, 자석 유무만 바꿔 같은 흔들림 비교 | 실제 덮개 고정, 수리 키트 | 두 물건에 같은 원리 적용 |
| 재료 · 4과09-01 | 흩어진 수리 부품 | 여섯 재료에 자석 접근, 붙는 철 운반, 먼/가까운 거리 비교, 같은 배치에 얇은 종이만 추가, 새 위치 열쇠 구조 | 수리 부품 회수, 힘 관찰 렌즈 | 재료·거리·장벽을 분리해 확인 |
| 극 · 4과09-02 | 사라진 극 표시·고리 장치 | 기준 N/S 양쪽 접근, 움직임으로 극 추론, 스티커 배치, 2개/3개 고리 띄우기와 붙이기 | 문과 고리 복구, 극 표시 스티커 | 같은 부품으로 다른 결과 만들기 |
| 원격 · 4과09-01·02 | 더러운 수조·미배송 택배 | 유리 밖 자석으로 내부 패드 추종, 세 오염 영역, 앞에서 당기기/뒤에서 밀기/역방향 운반 | 깨끗한 수조·배송, 원격 손잡이 | 속도보다 거리 조절과 극의 적용 |
| 발명 · 4과09-03 | 시민의 생활 불편 | 요청 물건 선택, 부품 직접 조립, 두 사용 조건에서 실제 작동, 힘 위치 화살표 | 자신의 설계도 → 광장 복구에서 사용 | 다른 장치 설계와 수정 시험 |

세부 성취기준 원문은 설정의 교사용 가이드에 수록한다. 이 앱은 교육과정의 탐구를 돕는 모형이며 실제 자석·물체 실험과 교사의 설명 관찰을 함께 사용한다. 얇은 종이의 결과를 모든 장벽으로 일반화하지 않는다. 자석을 전력 발생 원리로 설명하지 않는다.

보상은 실험 증거에 연결한다. 빠른 완료·실수 횟수로 차등 보상하지 않는다. 시설 복구와 다음 조작 도구 획득을 시각적으로 보여 준다. 소요 시간과 이해도 향상은 학생 실측 전에는 주장하지 않는다.
