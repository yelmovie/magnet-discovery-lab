## 3D를 적용할 만한 곳

판정은 지금처럼 2D 캔버스가 맡고, 3D는 **보기 전용**(카메라 각도 제한, 실패 시 2D 카드)으로만 쓰는 것을 권한다. `docs/DESIGN.md`의 "자유 3D 회전 쓰지 않음" 원칙과도 맞다.

| 우선 | 위치 | 왜 3D가 학습에 도움이 되나 | 방법 |
|---|---|---|---|
| ★1 | 극성 복원 센터 · 고리자석 쌓기(활동 6) | 마주 보는 **윗면·아랫면의 극**이 핵심인데 2D에서는 아랫면이 안 보인다. 기둥을 ±30° 돌려 보면 같은 극이 마주 보는 모습이 바로 보인다 | Three.js 고리 3개(원기둥 지오메트리, 윗면/아랫면 색 분리). GLB 불필요, 코드로 생성 |
| ★2 | 발명 공방 완료 · 광장 복구 · 인증서 | 내가 만든 장치(몸체+자석+철판)를 돌려 보는 보상. 성취감 직접 강화 | 기존 소품 그림으로 Meshy image-to-3D → 블렌더 정리 → GLB(1MB 이하) |
| 3 | 원격 제어 구역 · 수조 청소(활동 7) | "유리 안 패드 / 유리 밖 자석" 앞뒤 관계를 비스듬한 시점으로 보여 줌 | 설명 영상 또는 보기 전용 3D 장면 |
| 4 | 시작 화면 광장 분수(자석 코어) | 장식. 학습 효과는 낮음 | 우선순위 낮음 |
| ✕ | 도시 지도, 재료 분류·거리 실험 | 2D 그림 완성도가 이미 높고, 정밀 판정은 2D가 정확. 3D는 용량·저사양 태블릿 부담만 늘린다 | 적용하지 않음 |

Meshy 사용 시 모델 1개당 크레딧과 총량을 먼저 안내한 뒤 진행한다.
