## 최종 판정

**조건부 배포 가능**

이 판정은 사용자 요청으로 배포를 마친 뒤에 낸 것이다. 운영에는 이미 `c3ec848`이 올라가 있다.

### 왜 이 판정인가

- FAIL 1건은 D17이다. GPU 컨텍스트가 끊기면 고리 3D 보기 칸이 안내 없이 빈 칸이 된다.
- 이 FAIL을 조건부로 낮춘 근거는 세 가지다. 3D 보기는 선택 화면이고, 창을 닫고 다시 열면 새 캔버스로 복구되며, 실험대의 학습 흐름은 막히지 않는다. 저사양 기기에서 게임을 못 쓸 수준이 아니므로 D 영역 예외에 해당한다.
- A·F 영역과 B 핵심 경로(B3·B9·B10·B14·B17)에 FAIL이 없다.
- NOT TESTED 6건 중 A6과 F11이 A·F 영역에 있어 최대 판정이 조건부다.

### 처리할 조건

1. D17: `webglcontextlost` 처리와 안내 문구를 넣는다.
2. G21: 운영에 올린 `c3ec848`을 원격 저장소에 푸시한다. 지금은 로컬에만 있다.
3. A6·B16: 실제 학생 한 학급으로 난이도와 수업 시간을 확인한다. 교사가 첫 수업에서 확인한다.
4. F11: Suno 유료 구독 당시의 이용 조건 근거를 확인한다. 소유자가 보관 자료로 확인한다.

### 배포 후 확인할 것

1. C19·D10·G19: 실제 태블릿과 전자칠판에서 가장자리 제스처, 장시간 사용, 모바일 인쇄를 확인한다.
2. D11: 학교 Wi-Fi가 끊긴 뒤 새로고침하면 열리지 않으므로 수업 전에 알린다.

### 기타 실측

- 글자 대비: 운영 화면 4종(시작·지도·고리 실험·수첩) × 2크기에서 실제 픽셀로 쟀다. 측정한 표시 텍스트의 하위 10% 값 최저 4.51:1. 화면 읽기 전용 `sr-only` 2건은 오탐으로 제외했다. 45개 상태 전부를 잰 것은 아니다.
- 프레임: CPU 4배 감속에서 지도 대기·걷기, 고리 실험 대기가 60fps, 95백분위 프레임 16.8ms다. 이 PC의 대리 측정이며 3D 화면은 소프트웨어 렌더러라 제외했다.
- 오프라인: 연결을 끊고 새로고침하면 `ERR_INTERNET_DISCONNECTED`로 열리지 않는다. 앱이 켜진 상태에서는 끊겨도 시작 진행이 된다.
- WebGL: 생성 실패 때는 "3D 장면을 불러오지 못했어" 안내가 나온다. 컨텍스트 손실 때는 빈 칸이 되고 안내가 없다. Esc로 닫고 다시 열면 복구되며 오류는 없다.
- 캐시: 해시 파일까지 `public, max-age=0, must-revalidate`다. `public/_headers`가 없다.
