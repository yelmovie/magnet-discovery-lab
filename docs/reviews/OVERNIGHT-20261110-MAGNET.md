# 시트 9 자석 · 격리 고도화 검토

## 판정: 조건부 배포 가능, 운영 배포는 실행하지 않음

2026-11-10 · 기준 d34af0c · 브랜치 review/overnight-20261110-magnet.
원본의 예약 재개와 충돌하지 않도록 `_scratch/overnight-20261110-magnet` worktree에서만 수정했다. 원본 파일, 폰트, 학습 극 판정, 관찰 증거, 완료 조건, 보상 저장 키는 유지했다. 병합·푸시·운영 배포는 하지 않았다.

## 발견과 적용

1. 지도 악당은 기존 CSS 도형인 반면 4×2 고철 도깨비 시트가 이미 있었다. 원본 PNG와 정규화 JSON/WebP를 직접 확인하고 기존 177KB WebP를 재사용했다. 새로운 이미지 생성이나 원본 재가공은 하지 않았다.
2. 기본은 정지 프레임, 타격은 놀람/피격 프레임, 퇴장은 마지막 프레임이다. 상시 애니메이션을 추가하지 않았다. 이미지 실패 시 기존 CSS 캐릭터, 모션 감소 시 정지 상태, 정리 시 비동기 로드 콜백 해제를 유지했다.
3. 변경 전 지도 전체보기에서 공방 표지와 첫 악당이 1280×800, 1024×768, 915×412에서 겹쳤다. 두 악당 위치를 조정했다. 작은 화면 확대 보정으로 반복 타격 영역을 48.88×61.36 CSS px 이상 확보했다.
4. 전체보기의 악당 보조 라벨은 작은 화면에서 작다. 화면 확대/전체보기 해제로 더 크게 볼 수 있지만 가독성 경고는 남긴다. 폰트는 변경하지 않았다.
5. 레이아웃 검사에 AUDIT_ALL_SHOTS=1 선택지를 추가하고 이미지 로드·실패·연속 클릭 회귀를 추가했다.

## 확인한 결과

- 단위시험: 20파일 264개 통과. 저장 실패/복구, 극 판정, 고리 마주 보는 면, 증거와 잠금, 난수 조작 포함.
- TypeScript 및 Vite 빌드 통과. Three.js 676KB 청크 경고 유지. 선택적 3D 경로이며 기존 분리 구조 보존.
- playful-regression: 21개 통과. 10활동 증거 기반 완료, 수첩 오답 후 다음 버튼 잠금과 재시도, 저장/새로고침, 5구역·축제·인증서, 6해상도 실제 touch 입력, 재탐구 시 최초 증거와 발명 보존.
- 지도 악당 회귀: 잠금, 3회 타격, 터치/Enter/Space, 재진입·새로고침, 시연 저장 격리, 모션 감소, 정리 통과.
- 새 sprite 회귀: 이미지 성공/실패 양쪽에서 연속8회 클릭이1회로 제한되고 총3회 타격 뒤 추가 지급 없음, 저장 토큰·정리 통과.
- 릴리스 스모크: 로컬 생산 번들에서 1280×800·1024×768 시작/잠금/첫 조립/저장 복원, 3D고리, 수첩/축제/인증서, 초기화 통과. 첫 시도는 빌드 중 dist가 재생성되어 HTTP 실패했고, 빌드 완료 후 다시 실행해 통과했다.
- 로딩: 캐시 비활성, 12Mbps/지연80ms 모사. 시작 버튼 544ms/1761ms, 전송1,330,090바이트, 외부 요청0. 학교 Wi-Fi 실측이 아니다. 마지막 위치만 조정한 후 최종 번들도 별도 재빌드한다.
- graphify update 완료. 기존 ._pack 인덱스 경고는 그대로 보고하며 원본 Git 객체를 삭제하지 않았다.

## 화면 증거

`test-results/overnight-before`: 45상태×4크기=180측정. 첫3크기의 지도는 수정 전 캡처다. 검사 도중 별도 sprite 적용이 시작되어915×412는 시트 적용 후/위치 보정 전이므로 엄밀한 동일시점 시각 전후 비교에서 제외한다.

`test-results/overnight-after`: 180측정. 최종 위치 조정 직전 결과로915×412 지도 겹침1건이 남았고, 이를 다시 조정했다.

`test-results/overnight-map-final`: 변경된 지도만 1280×800·1920×1080·1024×768·915×412 재검증. P0/P1=0, SMALL-TAP=0. 다른 화면 코드는 그 사이 바꾸지 않았으므로 최종 합성 결과는180상태 P0/P1=0이다. 하나의 최종180상태 실행으로 주장하지 않는다.

네 크기의 최종 지도 스크린샷을 직접 확인했고, 1024×768 고리 활동과915×412 재료 분류도 직접 확인했다. 모든180장을 사람이 개별 검수했다는 뜻은 아니다. 915×412 시작/이야기/엔딩 일부는 세로 스크롤, 수첩/설정 일부는 내부 스크롤로 접근한다.

그 밖의 증거: `overnight-playful/results.json`, `overnight-villains-final/map-villains-qa.json`, `overnight-integration-final/`, `villain-sprite/`, `overnight-release/smoke.json`.

## 남은 조건

- 실제 학생 난이도·수업시간·학습효과, 학교 태블릿/전자칠판의 장시간 동작, iOS 인쇄/공유는 미검증이다.
- 교사 콘텐츠 검수 needsReview, 기존 Suno 이용허락 근거 확인을 유지한다.
- 200% 줌과 오프라인 재방문 제한은 기존 경고를 유지한다. 이번 릴리스 스모크도 offline=false다.
- 운영 릴리스는 원본 재개 결과와 안전하게 통합한 뒤 재빌드·운영 URL smoke가 필요하다. 현재 결과는 배포 준비용이며 배포 완료가 아니다.

edu-design, edu-final-check/score-rules/verdict-rules, game-common-design 원문, yelsam-design 고도화 절차와 Impeccable context/polish/craft-floor를 확인했다. 기존 범위 보존과 가독성·터치·상태 검증에 사용했다. 영상 신규 제작이 없어 HyperFrames를 쓰지 않았고, 기존 시트로 충분하여 imagegen을 사용하지 않았다.
