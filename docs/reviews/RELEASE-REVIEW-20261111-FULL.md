# 전체 리뉴얼 검토 · 2026-11-11

## 조건부 배포 가능

승인된 리뉴얼의 구현과 로컬 검증을 완료했다. 새 학습 경로, 기존 저장 이어하기, 완료 증거와 인증서 연결에서 진행 차단 오류가 발견되지 않았다. 실제 학교 기기·학생 수업·iOS 출력·현재 운영 URL은 미검증이며, 기존 음원 이용조건 근거 확인도 남아 있어 조건부 판정을 유지한다. 이번 작업 결과는 로컬 작업 트리에 있다.

점검에는 `edu-design`과 `edu-final-check`를 적용했다. 변경 영역을 직접 검증하고 변경하지 않은 영역의 판정은 11월 10일 보고서와 성적표에서 인용했다. 이전 부분 구현 검토 `RELEASE-REVIEW-20261111.md`는 당시 기록으로 보존했다. 현재 구현 범위와 결과는 이 보고서를 우선한다.

- 활동 2의 우편함 철판, 활동 3의 철 부품 분류와 길 복구, 활동 4의 틈 너머 열쇠와 거리·종이 비교.
- 활동 5의 같은 극으로 밀어 여는 문과 다른 극으로 당겨 여는 문. 두 문의 성공 증거가 있어야 완료한다.

- 활동 7의 유리 너머 수조 닦기, 활동 8의 중간 정차·유리벽 배송·반대 방향 귀환.
- 광장의 철 부품·거리·극·유리 연결 장치 네 개. 실제 조작 성공 후 수첩·엔딩·인증서로 이어진다.

- 기존 발명 활동과 저장 버전 2를 유지한다. 새 활동에는 `puzzleRevision: 2`를 넣고, 진행 중인 구형 활동과 이미 시작한 수첩·기존 인증서에는 새 조건을 강제로 추가하지 않는다.

## 외장 저장과 출력 검증

`/Volumes/T7 Shield`가 USB 외장·쓰기 가능 볼륨임을 확인했다. 작업 소스·의존성·빌드·검사 산출물·지정 캐시와 임시파일은 이 SSD에 저장했다. 검사용 Chromium headless shell도 SSD에 설치했고, `sandbox-exec`에서 외장 경로와 `/dev/null` 외 파일 쓰기를 차단한 상태로 실행했다.

이전에 확인한 일반 Chrome의 내장 Crashpad·metrics 경로는 기존 앱 설정으로 남아 있다. 기존 내장 데이터의 이동·삭제와 앱 전체 저장 경로 변경은 수행하지 않았다. 이번 검사 브라우저의 외장 저장 구성과 일반 Chrome의 설정을 구분한다.

운영체제의 다운로드·PDF 스트림 임시 저장이 샌드박스에 막혀 검사 경로를 보완했다. `TEST_CAPTURE_EXPORT=1`이면 앱이 실제 만든 PNG Blob을 캡처하고, PDF는 CDP의 Base64 반환으로 받아 SSD에 쓴다. PNG·PDF 바이트와 파일 형식을 검증했다. OS 저장 대화상자, 파일 수신 동작 및 실제 iOS 공유·인쇄는 미검증이다.
