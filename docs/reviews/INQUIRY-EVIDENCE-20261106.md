## 설계 결정

- 저장은 기존 `activity.values`, `records`, `trial.conditions`에 값을 더했다. 저장 버전, 검증, `missionReady`, `ready`, `completeActivity`는 바꾸지 않았다.
- 선택 대기는 다음 버튼 표시(`inquiryNext`)에서만 막는다. 값이 없는 이전 기록은 막히지 않는다.
- 자동재생은 학생 대신 예상을 고르지 않는다. 덮개를 닫는 단계에서 멈췄다가 학생이 고르면 이어 간다.
- 짝수 활동은 뒤따르는 발견 정리가 관찰 확인 역할을 하므로 질문을 더하지 않았다. 활동 5는 극 스티커를 학생이 직접 붙이므로 더하지 않았다.
- 예상 비교는 활동 1에만 넣었다. 나머지 활동은 수업에서 효과를 본 뒤 넓힌다.
- 이전 기록에는 표시를 지어내지 않는다. `manual`도 `autoplay`도 없으면 아무 표시도 하지 않는다.
- 학습 증거는 이 기기 안에만 저장한다. 새 개인정보를 받지 않고 외부로 보내지 않는다.

## 시험

```bash
npx vitest run --exclude '**/._*'
TEST_URL=http://127.0.0.1:4196/ node scripts/playful-regression.cjs
TEST_URL=http://127.0.0.1:4197/ TEST_FIXTURE=<완주 저장 JSON> node scripts/inquiry-evidence-regression.cjs
```

결과: 단위 258개, 학생 완주 회귀 21개(구역마다 재접속 포함), 새 회귀 30개, 자동재생 회귀 5개 통과. 태블릿 5개 해상도 205개 화면과 실제 터치 이벤트로 활동 1~8 통과.

- 태블릿 감사 후보 1종: 세로 화면(768×1024, 800×1280) 활동 6에서 `손 놓고 고리 관찰` 버튼이 고리 받침과 겹친다. 이번에 건드린 화면이 아니고 가로 화면에서는 나오지 않아 고치지 않았다. 수정 전 코드로 이 시험을 돌리지는 않았다.
- `release-smoke.cjs`는 이 맥에서 `[data-story="finish"]` 버튼이 안정 상태로 판정되지 않아 멈춘다. 수정 전 코드인 운영 사이트에서도 같다. 그 클릭만 강제로 바꾼 임시 사본으로는 로컬 빌드본이 통과했다.
- 태블릿 회귀에서 지금은 없는 구형 공방 조작(활동 9·10)을 뺐다. 활동 9·10은 학생 완주 회귀가 맡는다.

`TEST_FIXTURE`는 이전 빌드로 완주한 학생 저장이어야 이전 기록 호환을 시험할 수 있다. 이번 시험은 수정 전 코드로 `playful-regression.cjs`를 돌려 만든 `student.json`을 썼다.
