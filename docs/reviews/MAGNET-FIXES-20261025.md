브라우저 완주 검사는 격리된 테스트 저장소에서 DOM 버튼·공용 조작 이벤트와 기존 접근 검사를 통과하는 검증용 화면 이동을 사용한다. 화면 크기별 핵심 조작은 실제 마우스/키보드 및 Chrome이 생성하는 터치 포인터로 별도 검사한다. 도시의 모든 이동을 사람이 수동으로 완주했다는 의미는 아니다.
