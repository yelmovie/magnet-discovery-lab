## 수정한 내용

- 새 열쇠 퍼즐의 장치 설명·발견 문제·실험 사진 이름·광장 문제를 철 열쇠에 맞췄다. 이전 클립 실험 기록은 기존 문구와 정답 번호를 유지한다.
- 우편함 퍼즐은 철판 위치까지 바꾸므로 ‘자석만 바꾼 통제 실험’이라고 설명하던 안내·목표·기록 이름을 고쳤다. 한 조건씩 바꾸는 비교는 거리·종이 실험에서 명시적으로 다룬다.
- 핵심 문장을 굵기와 밑줄로 강조했다. 금속의 종류, 실제로 마주 보는 극, 색 표시, 거리의 조건, 종이·유리, 카트의 마찰을 구분해 설명한다. [IOP 자석 탐구](https://spark.iop.org/experiments-magnets), [Science World](https://www.scienceworld.ca/resource/magnets/), [뉴질랜드 교육부 비교 탐구](https://newzealandcurriculum.tahurangi.education.govt.nz/5637207632.p)
- 지금 조작할 물체·버튼에 일정한 테두리 표시를 붙였다. 선택 문제의 정답을 미리 강조하지 않는다. 열쇠 활동의 안내는 실제 ‘열쇠 움직임 관찰’ 버튼 이름과 맞췄다.
- 택배처럼 상단 장치 버튼이 숨겨지는 화면에서도 자꾸 도움말의 ‘장치·핵심 개념 보기’로 접근할 수 있다. 작은 가로 화면에서 추가 버튼이 겹친 부분을 발견해 별도 행으로 수정했다.
- 새 퍼즐의 장치 설명에는 현재 실험대의 자석·물체 배치를 확대해 보여 준다. 정리 단계에서는 저장된 관찰 장면을 사용한다.
- 공방의 ‘얇은 물체 너머’ 표현을 실제 관찰한 종이·유리로 구체화했다. 부품을 고른 뒤 그림판을 눌러 붙이는 순서와 힘 화살표 사용을 안내한다.
- 새 열쇠 퍼즐에서 움직이지 않은 거리를 시험한 결과도 관찰 기록으로 남긴다. 이 탐색으로 별을 깎지 않으며, 자동 관찰과 직접 수행은 기존처럼 분리한다. 이전 저장의 별과 관찰 기록을 일괄 덮어쓰지 않는다.

## 흥미·재미·이해·성취 설계

흥미는 도시 의뢰와 실제 조작 결과를 연결하는 기존 흐름을 사용한다. 재미는 정답을 미리 알려 주는 대신 여러 거리를 시험할 여지를 보장한다. 이해는 방금 움직인 물체와 설명의 대상이 일치하도록 개선했다. 성취는 실제 조작 증거와 학생의 정리 답을 별도로 확인한다. 이 설계의 수업 효과는 학생 관찰로 추가 확인해야 한다.

## 이미지 생성 대기

새 래스터 이미지 생성은 아직 수행하지 않았다. `imagegen` 스킬의 기본 도구가 `/Users/yel/.codex/generated_images`에 원본을 자동 저장하므로, 최신 외장 SSD 전용 저장 지침에 따라 이번 원본의 임시 저장 허용을 질문했다. 응답 전에는 호출하지 않는다. 기존 승인 그림과 실험대 캡처를 사용했으며, 캡처를 새 생성 이미지로 기록하지 않는다. 승강 발판 등 새 설명 그림의 생성·적용은 남은 항목이다.
