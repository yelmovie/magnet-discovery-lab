# 0.3.0 배포 후보 검증 · 2026-10-24

## 범위와 결론

5구역 10활동, 예상·근거 설명 10세트, 새 상황 적용 10개, 보고서→최종 복구→축제→이름 인증서까지 로컬 브라우저에서 실제 입력으로 완주했다. 자동 테스트는 완료 우회, 잘못된 과학 조건, 설계 수정 후 무효화, 최초 기록 보호를 확인한다. 실제 초등학생의 이해도·재미·소요 시간, 물리 태블릿 입력과 교실 네트워크는 미검증이다. 이 결과를 수업 효과 입증이나 현장 납품 승인으로 확대 해석하지 않는다.

기존 사용자 진행과 분리된 `127.0.0.1:5174`에서 검수했다. 배포 후보는 `npm run build`의 `dist/`이며 외부 서비스에 게시하지 않았다.

## 생성 이미지 검수

실험 도구와 실제 조작 위치·크기를 일치시켰다. 장면 아틀라스의 잘못된 반반 링 윗면은 사용하지 않는다. 올바른 빨강 윗면/파랑 윗면 두 고리와 기둥을 조합했다. 극·화살표·점선·센서·종이판·가변 얼룩 등 상태와 과학 의미를 가진 도형은 코드로 표시한다. 과거 Trial에 없는 극 방향을 만들지 않도록 기록 그림의 자석은 중립색으로 표현한다.

원본→WebP 픽셀·투명도·링 구멍·프레임 범위 검수는 [이미지 제작 기록](../ART-PRODUCTION-20261024.md)에 정리했다.
