- 보존 커밋 247e000의 지도 악당 연결과 에셋을 유지했다. 새 전투 기능이나 과학 학습 완료 조건은 추가하지 않았다.
- 요청한 나눔스퀘어네오 공식 정규·굵게 WOFF2와 OFL을 앱 내부에 포함했다. 제목·본문 토큰과 악당 라벨에 적용했다. 기존 폰트 원본은 보존했다.
- 기존 효과음 테스트가 첫 조립과 예측 선택을 중복 실행하던 문제만 수정했다.

## 실행 결과
- Vitest: 20 파일, 264 테스트 통과. 자석 극 관계·고리의 마주 보는 극·관찰 증거와 단계 잠금 검증 포함.
- TypeScript 및 Vite build 통과. 기존 Three.js 500 KB 청크 경고는 남아 있다.
- 지도 악당: 잠금, 터치/Enter/Space 3회 타격, 재진입·새로고침 보존, 교사 시연 저장 분리, 모션 감소, 정리 통과.
- 지도 통합 검사는 병렬 부하 중 한 차례 준비 타임아웃 후 단독 재실행 통과.
- 지도 조작: 1280×800, 1024×768, 820×540, 768×1024에서 끌기·취소·전체 보기·복원·단계 선택·일시 정지 통과.
- resume-review.cjs: 3해상도 제목/지도 스크린샷, 가로 넘침 없음, CDP 실제 NanumSquareNeoTTF-bRg 렌더링 확인. 화면 직접 확인.
- 실제 Chromium 음성 재생 시간 증가, 재생 교체 시 음성 요소 1개, 음소거 후 모든 미디어 정지 확인.
- experiment-audio-regression.cjs: snap/lid/pad/crate 네 실제 MP3 디코드·재생과 배경음 독립 효과음 음소거 통과.
- graphify update . 완료 (무시 경로).

기기 스피커 청취, 실제 태블릿 및 수업 이해도는 검증 범위가 아니다. 생성된 악당 스프라이트 원본은 보존했고 임의로 새 전투 연출에 연결하지 않았다. 상세 자동 검사 산출물은 test-results/에 둔다.
