사용자는 수정, 커밋, 푸시, 배포까지 직접 승인했다. 스킬의 기본 읽기 전용 범위보다 이번 요청의 실행 범위를 우선했다. 새 라이브러리나 외부 서비스는 추가하지 않았다.
