# 밀고 당기는 도시 — 탐험 UI 디자인 시스템

2026-10-21 · 디자인 / dokdo-design / iscream-settings의 화면 틀 적용

## 시각 방향과 역할

다섯 구역의 생성 일러스트를 화면 끝까지 펼치고, 같은 밀이·당이가 지도와 활동을 잇는다.
캐릭터·배경·소품의 묘사는 래스터 에셋, 실험의 극·거리·힘과 판정 대상은 정확한 캔버스,
누르기·설정·접근성은 DOM이 담당한다. 커다란 불투명 카드로 그림을 덮지 않는다.

우당탕 힘 실험실의 `recheck-final-map.jpg`를 실제로 확인했다. 그림 위에 이름표를 얹고
캐릭터와 길을 따라 건물로 가는 공간감은 이어받되, 기존 자석 캐릭터와 이번 도시의
금빛 석재·빨강/파랑 자석·진한 청록을 사용했다.

## 공통 컴포넌트

| 컴포넌트 | 적용 |
|---|---|
| `questHud()` | 좌상단 홈·이전, 우상단 소리·설정만. 시작 화면에서 홈·이전 숨김 |
| `questCompanion()` | 캐릭터의 `…`/`!`를 누를 때만 말풍선 열기. 메시지는 HTML 이스케이프 |

| `.quest-cta` / `.mission-cta` | 크림/금빛 본체와 아래 엣지, 눌림·포커스·비활성 상태 |
| `.expedition-*` | 1600×1000 지도, 현재/잠금/완료 이름표, 방향판, 다음 목적지 |
| `.mission-*` | 그림 위 질문, 그림 체크포인트, 넓은 조작 화면, 하단 한 개 주요 행동 |
| `.canvas-hit` | 실제 소품과 위치가 맞는 투명 DOM 터치/키보드 영역. 최소 48px |

조작 중 선택 테두리와 완료 체크를 함께 써서 색만으로 상태를 알리지 않는다.
다음 단계 버튼은 준비되었을 때 나타난다. 캐릭터 설명은 자동으로 열리지 않는다.

## 폰트와 한글

제목·버튼은 Jua 계열 **Magnet Quest Display**, 본문은 Pretendard 계열
**Magnet Quest Sans**를 `public/fonts/`에서 셀프호스팅한다. 외부 CDN 요청은 없다.
로컬 원본이 서브셋이고 원 라이선스에 Reserved Font Name이 있어, 네 파일의 내부
family/full/PostScript 이름을 새 이름으로 바꿨다. 원 저작권·OFL 메타데이터와
라이선스 원문 두 개를 동봉했다. 글리프·문자 범위·메트릭은 변경하지 않았다.

폰트 전체 약 923KB. Korean/Latin 제목 파일은 unicode-range로 나누어 필요한 범위만 읽는다.
`word-break: keep-all`을 공통으로 사용하며 버튼 글자는 기본 한 줄이다.

## 반응형·동작 줄이기

- 1024×600: 아이콘 48px, 질문 27px, 캐릭터 축소, 활동 화면 전체 유지.
- 1280×800: 기본 배치. 긴 설명은 캐릭터의 눌러 여는 말풍선에 둔다.
- 1920×1080: 아이콘·버튼·방향판·캐릭터가 커져 전자칠판에서 보인다.
- 759px 이하: 회전 강제창 없이 세로 스크롤 대체 레이아웃 제공.
- 시스템 `prefers-reduced-motion`과 앱 `.reduce-motion` 모두 반복 동작을 끈다.

## 변경과 확인

기존 게임 상태·저장·판정·기존 CSS는 수정하지 않았다. 신규 파일을 마지막 스타일 층으로
불러오며 `body.quest-mode`와 `#app`을 통해 적용 범위를 정한다. 새 helpers에는 레이아웃용
인라인 스타일이 없고 기존 마스코트의 포즈/크기 변수만 재사용한다.

- `quest-ui.ts` 단독 strict TypeScript 검사 통과.
- 네 WOFF2 파일의 내부 family/full/PostScript 이름 변경 확인.
- Jua/Pretendard OFL 원문 존재 확인.
- 생성 지도·생활 구역 실내·기존 제목 로고·캐릭터 원본 시각 확인.
- 실제 앱 통합 후 모든 스테이지와 세 해상도의 겹침·잘림·콘솔/네트워크 검사는 루트 작업에서 수행.

## 루트 통합 계약

`main.ts`에서 `quest.css`를 마지막에 불러오고 `body.quest-mode`를 붙인다.
HUD `data-action`: `home`, `back`, `sound`, `settings`.
캐릭터 `data-action="companion"`을 누르면 가장 가까운 `.quest-companion` 안의
`.quest-speech` hidden과 버튼 aria-expanded를 함께 바꾼다.
지도 이동·미션 판정·완료 버튼 표시·말풍선 바깥 클릭 닫기는 루트 로직이 담당한다.
