# 학습 흐름 개선 기록 · 2026-10-28

## 목표와 변경 범위

초등학교 학습자가 태블릿에서 직접 자석을 움직이며 관찰·비교·설계를 경험하도록 필수 조작과 반복 확인을 줄였다. 5개 구역과 10개 활동, 실제 실험 증거를 통한 완료 판정, 기기 내 저장 구조는 유지했다. 이번 작업은 로컬 개선이며 운영 배포는 하지 않았다.

## 공통 흐름

- 새 활동은 예상 선택 화면을 거치지 않고 바로 실험대에서 시작한다. 예상 질문은 펼쳐 볼 수 있는 선택 도움말이다.
- 매 활동마다 반복하던 규칙·근거 선택과 구역마다 두 번씩 수행하던 별도 현장 의뢰를 새 필수 진행에서 제외했다.
- 홀수 활동은 실험 증거를 갖추면 다음 활동으로 이동한다. 짝수 활동은 실험을 마친 뒤 구역별 발견 한 가지를 선택한다. 잘못 선택하면 실험에 연결된 힌트를 보여 주고 다시 고를 수 있다.
- 구역 완료 시 보상 화면 하나를 보여 준다. 개념 영상은 선택해서 보고, 보상 화면에서 다음 구역으로 바로 갈 수 있다. 도시를 둘러보는 경로도 남겼다.
- 마지막에는 자기 설계도를 광장 장치에 장착하고 실제 사용에 한 번 성공해야 축제와 인증서로 이어진다.

## 10개 활동 비교

| 활동 | 이전 필수 흐름 | 새 활동의 필수 경험 |
|---|---|---|
| 1. 숨어 있는 자석 찾기 | 두 생활 물건에서 같은 열기·관찰·걸쇠 반응을 반복 | 우편함 하나를 열고 자석을 관찰한 뒤 철 걸쇠의 반응 확인 |
| 2. 생활 장치 수리 | 두 물건의 자석 유무 비교와 세 번째 물건의 고장 진단 | 같은 우편함에서 자석 없음·있음을 같은 흔들기로 비교 |
| 3. 철 부품 분류 | 여섯 재료 검사·분류, 철 부품 두 개 운반 | 철 클립·알루미늄·나무를 검사·분류하고 클립 운반. 철못·플라스틱·고무는 선택 탐구 |
| 4. 거리와 종이 비교 | 먼 거리·가까운 거리·종이판 비교 후 열쇠 구조 | 세 조건 비교 유지. 같은 가까운 초기 배치에서 종이만 넣고 빼는 증거 필수 |
| 5. 극 표시 복원 | 미지 자석 두 개에 동일한 두 극 검사와 스티커 배치 반복 | 미지 자석 하나를 기준 N/S극으로 각각 검사하고 양끝 표시 복원 |
| 6. 고리자석 | 두 고리 띄우기, 세 고리 다시 배치해 띄우기, 세 고리 붙이기 | 같은 두 고리의 배치를 유지하고 띄우기·붙이기 비교 |
| 7. 수조 청소 | 세 얼룩마다 이동량과 왕복 횟수를 모두 충족 | 세 얼룩을 실제 패드 이동으로 닦기. 왕복 횟수 채우기 제거 |
| 8. 자석 배송 | 세 배송에서 중간 정차·점검·재출발 반복, 역방향 배송 | 앞에서 당기기와 뒤에서 밀기 두 배송. 목적지에서 자석을 떼어 정차 |
| 9. 발명 설계 | 몸체·자석·대상 배치 후 시제품 반응 시험 | 유지. 실패한 시제품도 결과를 관찰한 설계 경험으로 인정 |
| 10. 발명 사용 | 두 사용 상황 성공과 힘 화살표 배치 | 현재 설계의 실제 사용 성공 한 번. 설계를 고치면 바뀐 배치로 다시 시험 |

필수 반복을 줄였어도 실제 실험 없이 선택지만 눌러 완료할 수는 없다. 가까운 거리 비교와 종이 비교의 초기 배치 일치, 배송의 실제 이동·정차 증거, 발명 시험의 설계 버전 일치를 계속 검사한다.

## 성취기준과 연결

다음 대응은 앱에 수록된 2022 개정 과학과 성취기준을 기준으로 정리한 활동 설계다.

| 성취기준 | 남긴 학습 경험 | 확인할 증거 |
|---|---|---|
| 4과09-01: 자석과 물체의 반응을 관찰하고 힘의 특징 설명 | 생활 장치의 자석 유무, 철·알루미늄·나무의 차이, 거리와 종이 비교, 유리 너머 청소 | 재료 검사·분류 결과, 조건별 초기 배치와 반응, 안쪽 패드 이동 |
| 4과09-02: 자석의 반응을 극과 관련지어 설명 | 기준 두 극으로 미지 극 추론, 고리의 마주 보는 극 비교, 카트 당기기·밀기 | 두 극의 반응, 띄우기·붙이기 배열, 배송과 정차 결과 |
| 4과09-03: 생활을 편리하게 하는 자석 장치 설계 | 해결할 문제 선택, 부품 배치, 시제품 관찰과 필요시 수정, 실제 사용, 광장 적용 | 선택한 설계와 배치, 현재 설계 버전의 시험 결과 |

실험 완료와 발견 선택은 활동 중 확인 자료다. 학생이 힘의 특징을 자기 말로 설명하고 다른 실제 물체에도 적용하는지는 수업 관찰·대화·후속 활동으로 확인해야 한다. 게임 완주만으로 성취기준 전체 달성을 판정하지 않는다.

## 저장과 호환

- 새 시도에 `paceVersion: 1`, `inquiryVersion: 2`를 사용한다.
- 이미 진행하던 `playVersion: 4` 활동에는 새 필수 횟수를 소급 적용하지 않는다. 저장된 기존 탐구 단계와 완료 규칙으로 이어 간다.
- 새로 시작하거나 재탐구하는 활동에는 단축된 흐름을 적용한다. 완료한 구역의 최초 증거와 복구 기록은 재탐구로 덮어쓰지 않는다.
- 발명 설계를 수정하면 현재 설계와 맞지 않는 이전 사용 성공은 완료 조건에서 제외한다. 발견 정리 중이었다면 실험대로 돌아간다.
- 완료 버튼 연속 입력은 한 번의 완료 처리로 묶어 중복 전환을 막는다.

## 검증 상태와 한계

최종 단위 테스트 10개 파일·125개 사례와 타입 검사·프로덕션 빌드가 통과했다. 격리된 Chromium에서 10개 활동 → 5개 발견 정리 → 최종 복구 → 인증서 → 새로고침까지 완주했다. 재탐구의 최초 증거 보존, 원격 운반 발명품의 실패 배치 → 수정 → 현재 설계 사용 → 광장 적용도 통과했다. 콘솔의 미처리 오류와 HTTP 400 이상 응답은 검출되지 않았다. 기존 선택형 3D 모듈의 500 kB 초과 빌드 경고는 남아 있다.

- 단위 검사: `npm test`
- 타입 검사·프로덕션 빌드: `npm run build`
- 새 활동 브라우저 회귀 검사: `npm run test:browser` (`scripts/playful-regression.cjs`)
- 브라우저 실행 결과·캡처: `test-results/playful-20261028/`

브라우저 검증에서 1024×768 화면으로 모든 활동의 실험대·행동 버튼·다음 버튼이 화면 안에 있는지 확인했다. 1280×800, 1024×768, 768×1024에서 첫 활동의 실제 터치 탭-배치 입력도 통과했다. 전체 완주에서는 키보드·탭 배치가 공유하는 물체 배치 이벤트와 실제 UI 버튼을 사용했다. 모든 활동을 실제 손가락 드래그로 검증한 것은 아니다. 태블릿 크기의 화면·터치 입력 에뮬레이션은 실제 태블릿 검증과 구분한다.

실제 iPad·Android 태블릿과 전자칠판의 입력감, 학생별 흥미·이해도·소요 시간, 교실 동시 접속은 이번 로컬 검사로 확인하지 못한다. 학생 관찰 없이 학습 시간 단축 비율이나 성취도 향상을 수치로 주장하지 않는다.
