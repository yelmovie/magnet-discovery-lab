# 이미지 표시 복구 · 2026-10-25

사용자 화면에서 도시 지도·캐릭터·택배 그림이 사라지고 이미지 대체 텍스트가 표시되는 현상을 재현했다. 5174 포트에서 실행 중인 서버가 없었고 브라우저에는 Vite 연결 종료 오류가 남아 있었다. 로컬 파일 유실이 아닌 서버 중단으로 확인했다.

- 기존 주소 `http://127.0.0.1:5174/`에 Vite를 별도 숨김 프로세스로 재실행하고 페이지를 다시 불러왔다. 진행 기록은 유지했다.
- 도시·재료·장비 파일 HTTP 200과 image/webp 응답을 확인했다.
- 소스에 직접 표기된 정적 에셋 경로 26개에 누락 파일이 없었다.
- 실제 공용 렌더 코드로 재료 6종·실험 장비 6종·장면 6종을 브라우저에서 표시해 확인했다.
- `src/art.ts`: 고정 512px 셀을 넘어간 수조 장면의 철로를 포함하도록 표시 범위를 수정하고 옆 발명 장면의 철로 파편을 제외했다.
- `src/production.css`: 고리 두 개의 간격을 벌려 떠 있는 상태가 명확하게 보이게 했다.
- `npm run build` 통과. 게임 지도 화면의 깨진 img 요소 0개 확인.

검수 도구 화면은 `test-results/art-check.html`, 캡처는 `test-results/production-20261025/`에 있으며 배포 출력에는 포함되지 않는다. PC를 재시작하면 로컬 서버도 다시 실행해야 한다. README에 동일 주소 재실행 명령을 추가했다.
