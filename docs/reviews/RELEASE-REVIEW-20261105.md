# 밀고 당기는 도시 · 전체 스테이지 최종점검

**판정: 조건부 배포 가능.** 로컬 완주·저장·화면 검사에서 진행을 막는 문제는 발견되지 않았다. 실제 수업 기기와 학교망은 아직 확인하지 않았고, 연결이 끊긴 뒤 새로고침하면 다시 열리지 않는다. 배포한 버전은 이번 변경과 다르다.

- 2026-11-05 · `codex/magnet-quest-upgrade-20261021` · 기준 커밋 `a47ce73` 위의 작업 트리.
- Cloudflare Pages `magnet-city`, 출력 `dist/`. 직전 운영 배포 `2495e2f2`, 배포 기록은 [2026-11-04 기록](MAGNET-RELEASE-20261104.md). 이번에는 운영 배포·푸시를 하지 않았다.
- 수업 전: 실제 태블릿과 전자칠판에서 터치·가로세로 전환·교실 거리 글자 크기와 첫 로딩을 확인한다. 학생 플레이 시간과 자기 말로 설명하는 능력도 함께 확인한다. QR·인앱 브라우저, iOS 인쇄와 학교 Wi-Fi 끊김은 그 기기에서 별도로 확인한다.

## 실행과 증거

- macOS·Chrome·Playwright. 작업·브라우저 임시 프로필·산출물은 T7 Shield. 기존 설치를 사용했고 새 의존성 설치는 하지 않았다.
- `npm test`: 17파일 225개 통과. `npm run build`: TypeScript와 Vite 통과. 별도 lint 스크립트 없음. 실제 배포 파일 186개, 59,386,273바이트, Finder 메타데이터 0개. 1KB 이상 파일의 동일 SHA-256 중복 없음.
- `npm run test:browser`: 21개 확인 통과. 10개 활동과 잘못된 답의 재시도, 수첩 5문항, 6가지 화면 크기 터치, 재탐구 및 PNG 저장. 자동화 완주 시간은 학생 수업 시간으로 환산하지 않았다.
- `layout-audit.cjs`: **45개 상태 × 7개 해상도 = 315건**. 1920×1080, 1280×800, 1024×768, 1024×600, 915×412, 830×515, 375×812. 실제 전체 페이지 캡처도 함께 확인했다. 버튼 가림·겹침·텍스트 잘림·가로 스크롤·콘솔 오류 0건. 스크롤 검출 40건(페이지 20, 화면 내부 15, 팝업 5). 일부 좁은 화면의 긴 수첩·인증서 및 설정·가방에서 세로 또는 내부 스크롤.
- 배포용 빌드에서 시작·시설 잠금·첫 조립·저장과 복원, 고리 3D, 수첩·축제·인증서, 초기화 취소/확정을 확인했다. 인증서 인쇄 PDF는 두 크기에서 A4 가로 1장이다.
- 오디오: 조립과 실험의 물리 효과음 4종 실제 재생, 배경음과 독립적으로 음소거. 자동재생: 재료·수조·배송이 관찰을 저장하며 발견 정리의 답은 누르지 않는 것을 확인했다.
