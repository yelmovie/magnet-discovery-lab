# 최종 점검 · 2026-10-21 · v0.2.0

사용자가 승인한 디자인·활동·캐릭터·보상 고도화를 실제 앱에 반영했다. 로컬 구현은 완료했으며 외부 배포·원격 푸시는 하지 않았다.

## 확인한 결과

- `npm test`: **55개 통과**. 기존 37개, 오디오 5개, 새 증거·설계·도로·첫 프레임 회귀 검사 13개.
- `npm run build`: TypeScript·Vite 통과. 실행 JS 약 123 KB / gzip 44 KB, CSS 약 139 KB / gzip 31 KB. 이전 Phaser 도시 런타임은 새 진입 번들에서 제외됐다.
- 격리된 주소 `127.0.0.1:5181`의 새 기록으로 1~10 활동 → 5개 증거 → 보고서 → 설계도 장착 → 광장 실제 작동 → 축제 → 인증서까지 직접 진행했다.
- 우편함의 먼 배치를 실제 실패시킨 뒤 고쳐 두 사용 조건을 재시험했다. 원격 발명 대체 경로도 재탐구로 완수했고 최초 완료·설계·증거가 보존됐다.
- 생활 구역의 추가 의뢰는 철판이 멀어 열리는 상태와 수정 성공을 재탐구로 검증했다. 마우스 드래그·방향키·물체 선택 후 위치 누르기를 사용했다.
- 재진입 때 첫 RAF 시간이 약간 이르면 택배 경로 인덱스가 음수가 되는 오류를 발견했다. 시간 차이를 0 이상으로 제한하고 음수·NaN·순환 경계 회귀 검사를 추가했다. 수정본에서 재진입·재탐구 후 새 콘솔 오류가 없었다. 설계가 바뀐 뒤 예전 성공으로 끝내지 않고 재장착할 수 있도록 별도 회귀 검사도 추가했다.
- 설정에서 음악 끄기 시 음량 비활성화, 원문 성취기준, 전체 해금과 원래 진행 복귀, 초기화 취소 우선 포커스를 확인했다. 실제 초기화는 실행하지 않았다.

## 화면·에셋 검증

906×755 / 1280×800 / 1920×1080 / 873×580의 **4개 CSS 뷰포트**에서 시작·지도·활동 10개·광장 3상태를 같은 렌더러의 QA 화면으로 띄워 **60개 상태**를 검사했다. 화면 밖의 지도 건물과 닫힌 도움말 내부는 검사 대상에서 제외했다. 작은 터치 영역(48 px 미만)·화면 밖 고정 조작부·문서 가로 넘침 0건. 고리 버튼 겹침·가장자리 레이블 잘림·수조 패드 가림은 수정 후 재확인했다.

이 검사는 데스크톱 브라우저의 컴포넌트 검사다. 보고서·인증서·설정까지 모든 페이지를 네 실기기에서 실행했다고 표현하지 않는다. 세로 화면에는 가로 회전 안내를 추가했으며 세로 사용성·실제 터치 장치는 별도 확인이 필요하다.

새 생성 그림은 지도 1장·실내 5장·소품 6종, WebP·atlas 약 2.29 MB다. 기존 로고는 무손실 WebP 1.39 MB로 변환했고 알파·합성 픽셀 동일성을 확인했다. 첫 화면의 지도·로고·캐릭터·모든 폰트·번들을 합친 보수적 파일 예산은 약 **3.68 MB**다. 새 주소의 로컬 배포본에서 탐험 시작 버튼을 읽기까지 약 **3.5초**였으며 브라우저 제어 오버헤드를 포함한 벽시계 측정이다. 교실 와이파이·LCP 측정값으로 대체하지 않는다.

검사 산출물은 `test-results/quest-responsive-matrix-final.json`, `quest-final-*.png`, `quest-load.json`에 있다. 이 폴더는 Git에서 제외한다. 그림 프롬프트·원본·해시는 별도로 버전 관리한다.
