# Suno 배경음 연결 · 2026-10-25

사용자가 제공한 연주곡 두 개를 원본 변경 없이 정리했다.

| 용도 | 제공 파일명 | 배포 경로 | 길이 |
|---|---|---|---|
| 메인 | Main_Curious Discovery.mp3 | public/audio/music/main-theme.mp3 | 약 78초 |
| 파이널 | Final_Victory in the Town Square.mp3 | public/audio/music/finale-theme.mp3 | 약 74초 |

원본은 `assets/source/audio/suno/*-original.mp3`, 파일 크기·SHA-256·제공 파일명은 같은 폴더의 `tracks.json`에 보관했다. 프로젝트 최상위에 있던 MP3는 이 원본 폴더로 이동했다. 그 밖의 기존 자료는 이동하지 않았다.

## 재생

- 시작 화면·도시·탐구·보고서·최종 복구에서 메인 테마를 반복한다. 화면 전환 시 같은 플레이어의 재생 위치를 유지한다.
- 엔딩 진입 시 파이널 테마를 처음부터 재생한다. 인증서로 전환해도 이어지며 곡이 끝나면 멈춘다. 엔딩 다시 보기는 처음부터 재생한다.
- 플레이어는 한 개만 사용한다. 도시로 돌아가면 메인 테마로 전환한다.
- 브라우저 정책에 따라 첫 터치·키 입력 뒤에 소리를 시작한다. 자동 재생 거부 시 다음 조작에서 다시 시도한다.
- 이야기·개념 영상과 백그라운드 전환 시 일시 중지하고 돌아오면 같은 위치에서 이어진다.
- 배경음·효과음 개별 스위치와 상단 전체 음소거를 제공한다. 기존 배경음 음량 값(기본 35%)을 유지한다.
- 효과음 전용 배포본의 강제 music=false는 새 음원 버전으로 한 번 마이그레이션한다. 전체 음소거와 이후 개별 배경음 선택은 보존한다. 학습 기록 구조는 변경하지 않는다.

## 검증

- 두 원본 전체 FFmpeg 디코딩 성공, 런타임 복사본과 원본 SHA-256 일치.
- 자동 검사 95개 통과, TypeScript·Vite 운영 빌드 성공.
- 별도 포트의 운영 빌드에서 시작·도시 이어 재생, 음악 스위치, 이야기 중 일시 중지, 파이널 전환, 인증서 이어 재생(30초 시점), 다시 보기, 전체 음소거, 도시 복귀 시 메인 전환을 실제 UI로 확인했다. 한 개 플레이어와 브라우저 콘솔 오류 없음도 확인했다.
- 배포 후 실행 파일과 MP3의 실제 바이트를 로컬 dist와 비교한다. 결과는 `test-results/music-deployment-20261025/`에 보관한다.
