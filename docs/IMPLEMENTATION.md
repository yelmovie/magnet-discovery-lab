# MVP 구현·검증 기록

## 2026-10-18 태블릿 탐구 경험 개편

[태블릿 실제 구현·검증 기록](TABLET-IMPLEMENTATION-20261018.md)이 최신 상태다. 10개 활동·기록 서랍·v1→v2 저장 이전·최종 기본/선택 도전을 실제 앱에 반영했다. 아래 내용은 이전 버전의 이력이다.

## 2026-10-15 활동·아트 개편

현재 구현은 [활동·아트 개편 기록](ADVENTURE-UPDATE-20261015.md)을 우선 참고한다. 10개 활동의 직접 조작·반복 실험·실패 후 수정, 생성 이미지 지도와 캐릭터, 도구 보상과 최종 설계 연결을 반영했다. 자동 테스트 23개와 빌드를 통과했고, 정상 학습 경로로 엔딩·인증서까지 직접 확인했다. 아래 내용은 이전 버전의 이력이다.

## 2026-10-12 공통 탐색·관리자 설정 변경

- 모든 화면 좌측 상단: 홈·직전 페이지. 방문 이력이 없으면 이전 버튼 비활성화.
- 모든 화면 우측 상단: 연구 기록·소리·톱니바퀴 설정. 좁은 화면에서도 소리·설정 아이콘을 숨기지 않는다.
- 관리자 전체 해금: 하나의 선택으로 전 활동과 최종 장면 접근. 설정 안의 단일 목록에 모든 바로가기를 표시한다. 장별 토글이나 단계별 해금은 없다.
- 관리자 모드는 현재 실행의 미리보기다. 저장 상태를 복제해 사용하고 학습 저장을 중단한다. 끄면 원본으로 돌아가며, 새로고침해도 원래 저장 데이터로 시작한다. 인증서에도 미리보기 표시가 붙는다. 관리자 인증·권한 보안을 제공하는 서버 기능은 아니다.
- 실험 성공 조건은 유지한다. 관리자 해금이 증거 자동 획득이나 수료 처리로 기록되지 않는다.
- 자동 테스트 **19개 통과**, TypeScript·Vite 빌드 성공. 기존 Phaser 청크 크기 경고는 동일하다.
- 이번 변경의 실브라우저 클릭·반응형 재검증은 브라우저 제어 도구 초기화 오류로 수행하지 못했다. 개발 서버 HTTP 응답은 확인했다. 아래의 완주·화면 검증 기록은 9월 23일 MVP 버전 기준이다.

기준일: 2026-09-23. PRD/TRD/DESIGN은 계획 문서이며 이 파일은 실제 구현 상태를 기록한다.

## 구현 범위

| 구역 | 실제 활동 | 결과 |
|---|---|---|
| 1. 생활 자석 조사국 | 01 보관함·책갈피 열기, 예상, 내부 관찰 / 02 자석 넣기·빼기 비교 | 생활 자석 조사 증거, 복구 20% |
| 2. 힘 실험 연구소 | 03 여섯 재료의 반응 / 04 거리·종이 사이 조건 비교 | 힘 반응 실험 증거, 40% |
| 3. 극성 복원 센터 | 05 미지 자석을 N·S로 비교 / 06 막대에 끼운 고리자석 뒤집기 | 극성 판별 증거, 60% |
| 4. 원격 제어 구역 | 07 수조 바깥 자석으로 안쪽 패드 이동·청소 / 08 카트 앞에서 끌기·뒤에서 밀기·방법 선택 | 원격 제어 증거, 80% |
| 5. 시민 발명 공방 | 09 보관함 또는 부품 운반 도구 설계 / 10 시험·실패 원인 확인·수정·재시험 | 발명 증거, 95% |
| 최종 | 증거 보고서 → 극·고리·거리 조건으로 자기 코어 복구 → 24초 엔딩 → 인증서 | 복구 100% |

퀴즈 정답만으로 활동을 넘기지 않는다. 필요한 조작과 관찰이 기록되어야 완료된다. 발명 시험 결과는 템플릿과 수정 번호가 모두 일치해야 유효하다. 도시의 시설 상태와 동작은 획득한 증거에 따라 바뀐다.

## 구현 선택과 계획 대비 차이

- 도시 선택에만 Phaser 3을 지연 로드한다. 활동은 DOM·SVG·Canvas 2D로 구현하여 텍스트와 입력 컨트롤을 웹 요소로 유지했다. 전체 활동을 Phaser 장면으로 구성하는 초기 TRD와 다르다.
- 도시 논리 해상도는 480×320이다. 길 찾기, 건물 입구 이동, 잠금, 앞뒤 가림을 구현했다. 최종 다방향 캐릭터 스프라이트 대신 코드로 그린 작은 캐릭터와 걷기 동작을 사용한다.
- 1·2장 보관함·책갈피 등은 2D 내부 보기다. 3D 회전과 핀치 확대는 포함하지 않는다.
- 카트는 앞·뒤·자유 선택의 3개 운반 구간이다. 장애물을 자유 배치하는 물리 퍼즐은 아니다.
- 발명은 두 템플릿의 위치·거리·극·상대 부품을 조절한다. 템플릿별 배치 보존과 직전 배치 되돌리기를 제공하며 다단계 편집 이력은 포함하지 않는다.
- 화면은 반응형이며 작은 높이에서 세로 스크롤을 허용한다. 가로 방향을 권장하지만 세로 화면을 강제로 차단하지 않는다. 회전·포커스 이탈 시 청소와 카트의 계속 눌림을 해제한다.
- 엔딩은 SVG/CSS 기반 장면 애니메이션이다. 영상 파일이나 AI 생성 영상은 아니다. 건너뛰기와 다시 보기를 제공한다.
- 자석 반응은 학습용 정성 모델이다. 실제 힘의 단위·정밀 물리 계산을 제공하지 않는다.
- 계정, 서버 저장, 교사용 대시보드, 완전 오프라인 설치는 구현 범위 밖이다.

## 제공 자료 사용

원본 파일은 수정하지 않았다. `public/assets/logo.png`는 제공된 `ChatGPT Image 2026년 9월 23일 오후 09_58_17.png`, `material-lab.png`는 `ChatGPT Image 2026년 9월 23일 오후 09_58_05 (3).png`의 복사본이다. `lab.png`는 `ChatGPT Image 2026년 9월 23일 오후 09_58_04 (1).png`의 복사본이며 현재 화면에서는 사용하지 않는다.

기존 샘플의 크림색·초록·빨강/파랑 자석 분위기를 반영했다. 밀이·당이는 제공 시트의 U자 형태와 기록 소품을 참고한 간단한 SVG 버전이다. 장면 전체 이미지를 버튼으로 덮는 방식 대신 조작 가능한 오브젝트와 HTML 텍스트를 사용했다.

## 자동 검증

`npm test`: **17개 통과**. `npm run build`: **TypeScript 검사 및 Vite 빌드 성공**.

- 극의 인력·척력, 재료별 반응, 거리 경계, 고리의 마주 보는 극, 카트 방향
- 필수 관찰 없이 활동 완료 불가, 순서 잠금, 거리 비교의 통제 조건
- 증거 중복 생성 방지와 최초 기록 보존, 95%와 최종 100% 구분
- 수조 오염 셀 계산과 이동 구간 청소
- 발명 위치·거리·극에 따른 작동, 수정 후 이전 시험 무효화, 템플릿 간 시험 결과 재사용 방지
- 저장 형식 검사, 저장소 차단 시 메모리 진행과 저장 실패 표시, 지원하지 않는 버전의 기존 데이터 보존

Phaser가 포함된 도시 청크는 약 1.22 MB, gzip 약 337 KB로 Vite의 500 KB 경고가 남는다. 도시 진입 시에만 읽는 별도 청크이며 빌드 오류는 아니다. 실제 기기 다운로드·첫 진입 성능은 미측정이다.
