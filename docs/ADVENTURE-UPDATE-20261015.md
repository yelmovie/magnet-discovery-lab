# 자석 탐험 활동·아트 개편 — 2026-10-15

## 적용 내용

단순 선택 위주였던 활동을 `예상 → 직접 조작 → 반응 관찰 → 수정 → 다른 상황에 적용`으로 바꿨다. 도시에서 의뢰를 받고, 밀이·당이와 문제를 해결하며, 도구와 연구 기록을 얻어 다음 구역으로 진행한다. 시간 제한이나 클릭 횟수로 보상을 주지 않는다.

| 구역 | 해결할 문제·실제 조작 | 완료 후 얻는 것과 다음 활동 연결 |
|---|---|---|
| 생활 자석 조사국 | 보관함·책갈피를 열어 자석 꺼내기. 두 물건을 자석 없이/넣고 각각 닫아 비교하기 | 자석 수리 키트, 생활 자석 조사 기록. 다음 연구소에서 검사 자석 사용 |
| 힘 실험 연구소 | 여섯 재료 예상 분류 → 자석으로 검사 → 잘못된 분류 수정. 멀리/가까이/종이 사이 세 조건 비교 | 힘 관찰 렌즈와 재료·거리 기록. 다음 센터에서 끌림·밀림 관찰 |
| 극성 복원 센터 | 알려진 극으로 반응을 비교하고 미지 자석 두 개의 극 표시. 고리 두 개를 끼우고 세 가지 간격 주문 해결 | 극 표시 스티커와 극성 기록. 수레의 마주 보는 극을 이용 |
| 원격 제어 구역 | 수조 바깥 자석으로 연속 청소. 수레 앞에서 당기기·뒤에서 밀기·반대 방향 배송, 자석을 멀리 떼어 정차 | 원격 조작 손잡이와 운용 기록. 공방에서 판 너머 운반 장치 설계 가능 |
| 시민 발명 공방 | 우편함 또는 원격 운반 도구 선택. 몸체·자석·상대 부품을 배치하고 두 상황에서 시험. 실패 시 설계 수정 | 실제 배치·시험 기록이 있는 내 설계도. 최종 관제소의 잠금/고정판에 적용 |

보상은 구역 진입 권한 및 다음 활동의 도구 설명과 연결된다. 마지막 설계도는 저장된 설계와 유효한 시험 결과를 확인한 뒤 최종 장치 상태를 실제로 바꾼다. 캐릭터의 안내·성공 포즈도 실험 결과에 따라 바뀐다.

## 교육과정 연결

[교육부 2022 개정 초·중등학교 교육과정 확정 자료](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)의 과학과 교육과정 원문을 대조했다. 아래는 원문 인용이 아닌 활동 대응 요약이다.

- [4과09-01]: 자석과 물체의 반응 관찰 → 재료 예상·검사·분류 수정, 거리·종이 조건 실험.
- [4과09-02]: 자석과 자석 사이의 힘을 관찰하고 극의 성질 탐구 → 알려진 극·미지 극 비교, 고리 배열, 수레 조작.
- [4과09-03]: 자석의 성질을 생활 문제 해결에 이용 → 생활 장치 수리, 발명 설계·실제 시험·수정, 관제소에 적용.

힘은 정성적으로 표현한다. 자기장·자력선·발전 원리나 정확한 힘의 수치는 가르치지 않는다. 실제 학생의 이해도·재미·수업 소요 시간은 아직 측정하지 않았다.

## 아트와 파일

- 새 생성 이미지 4종: 도시 지도, 밀이 4포즈, 당이 4포즈, 보관함·책·덮개 부품 시트. 사용자 제공 캐릭터를 참고했다.
- 제공된 실험실·재료실·공방 이미지 3종을 배경으로 재사용했다.
- 실행 에셋: `public/assets/adventure/*.webp`, 7개 합계 **3,537,850 bytes**. 배경은 품질 88, 투명 캐릭터·부품은 무손실 WebP다.
- 원본 보관: `assets/source/adventure/*.png`. 원본은 배포 폴더 밖에 두었다.
- 지도는 생성 이미지 위에 실제 길 그래프를 두고 캐릭터를 이동시킨다. 480×320 좌표계에 960×640 캔버스를 사용한다. 활동은 기존 방침대로 2D다.
- 주요 코드: `src/adventure.ts`, `src/manipulation.ts`, `src/adventure.css`, `src/city.ts`, `src/main.ts`, `src/art.ts`, `src/domain.ts`.
