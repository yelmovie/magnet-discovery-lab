# 캐릭터 한국어 음성

마을 주민 5명, 시민 발명 공방 주민 5명, 밀이·당이에게 각자 역할에 맞는 합성 목소리를 배정했다. 모모 자비스의 로컬 한국어 음성 합성으로 만든 36개 대사를 MP3로 넣었다. 게임은 음성 파일만 재생하므로 모모나 음성 생성 서버에 접속하지 않는다.

F1은 모모의 Supertonic 3 기본 음성이고, 나머지는 Qwen3-TTS 합성 프리셋이다. 재료 연구원과 수조 관리인은 같은 연령대의 공방 주민과 다른 높이와 속도로 마감했다. 발명가는 원래 목소리를 유지하고 말의 시작과 자음을 또렷하게 다듬었다. 실제 사람의 녹음이나 목소리를 쓰지 않았다. 공방 주민의 얼굴을 누르면 사연을 읽고, ‘목소리 듣기’로 다시 들을 수 있다. 설정의 **효과음·캐릭터 목소리**로 인물 음성도 함께 켜고 끌 수 있다.

- 지도 주민: `public/audio/voices/resident-{1..5}-{hello|again|news|science}.mp3`
- 공방 주민: `public/audio/voices/workshop-{eraser|pins|bag|door|cup}.mp3`
- 밀이·당이: `public/audio/voices/mascot-{mili|dangi}-title.mp3`, `public/audio/voices/story-{intro|final}-{번호}.mp3`

`public/audio/voices/manifest.json`에 대사 원문, 목소리 ID, 파일 길이, SHA-256을 기록했다. 바뀐 대사를 만들 때는 모모 자비스에서 같은 목소리 ID와 언어 `ko`를 사용한다. 긴 대사는 문장별로 생성해 연결할 수 있다. 적용본은 모노 44.1kHz, 96kbps MP3로 만들고, 영상 대사는 자막 시간에 들어오도록 긴 무음을 줄이고 필요한 경우 속도를 맞춘다.

이전 Supertonic 2 생성 코드와 라이선스 사본은 과거 버전의 제작 기록이다. 현재 음성을 만들거나 게임을 빌드하는 데 필요하지 않다.
