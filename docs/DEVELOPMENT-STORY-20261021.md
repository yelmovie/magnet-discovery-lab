# 밀고 당기는 도시 제작기

출발점은 초등학생이 화면의 정답 탭을 고르는 데 익숙해지고, 자석의 성질은 충분히 관찰하지 못하는 문제였다. 교실의 자석·철 물체·고리 실험을 닮은 직접 조작을 중심에 두었다.

2022 개정 과학의 `[4과09-01]` 물체와 자석의 힘, `[4과09-02]` 극과 반응, `[4과09-03]` 생활 장치 설계를 다섯 시민 의뢰로 연결했다. 그림은 도시와 장소·생활 소품을 맡고, 정확한 극 표시와 거리·움직임은 Canvas 모형이 맡는다. 같은 좌표를 사용하는 DOM 타깃을 얹어 터치·키보드·눌러 이동을 지원한다.

아이의 조작은 처음 위치·경로·조건·결과를 가진 실험 기록으로 남긴다. 완료한 증거는 사본으로 고정하며 재탐구가 최초 증거를 덮지 않게 한다. 이해도는 완료 횟수로 자동 판정하지 않고 자신의 그림을 보며 설명하도록 교사에게 연결한다.

지도·실내·소품은 프로젝트용으로 생성하고 WebP로 압축했다. 소리는 외부 파일 없이 합성하고, 폰트는 OFL 원문을 포함해 자체 제공한다. 실제 학생의 이해도와 수업 시간은 측정하지 않았으므로 효과를 실증했다고 표현하지 않는다.
