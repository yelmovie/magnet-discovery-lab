# 밀고 당기는 도시 0.3.0 — 납품 전 고도화

작성일: 2026-10-24. 배포 후보 빌드는 `dist/`. 실제 외부 배포는 하지 않는다.

## 바꾼 플레이 경험

기존 5구역·10개 활동과 이동 도시, 등장인물, 최초 학생 기록을 유지한다. 새 탐구는 예상 → 실제 조작 → 규칙과 실험 근거 연결 순서로 진행한다. 각 구역의 두 번째 활동은 서로 다른 새 상황 두 가지에 적용해야 복구된다. 기존의 “이야기했어” 자기확인 버튼으로 구역을 완료하는 경로를 없앴다.

10개 탐구에 예상과 근거 설명, 5구역에 현장 의뢰 10개를 추가했다. 과도한 제한시간·체력 차감은 없다. 틀린 예상은 실험 진입을 막지 않는다. 실패한 설계는 관찰 가능한 결과와 수정 단서를 주고, 현재 활동에서 다시 시험한다. 수업 시간은 35~50분을 설계 목표로 삼으며 실제 학생 표본으로 측정한 값은 아니다.

| 구역 | 실제 조작·판단 | 현장 의뢰 | 다음 활동으로 이어지는 보상 |
|---|---|---|---|
| 생활 자석 조사국 | 두 보관함 내부 조사, 꺼낸 자석으로 철 걸쇠 반응 확인, 같은 힘에서 자석 유무 비교, 고장 증거를 본 뒤 철판 위치 진단 | 새 잠금장치 수리, 얇은 종이 덮개 너머 수리 | 자석 수리 키트 |
| 힘 실험 연구소 | 여섯 재료 실제 검사, 결과대로 직접 분류, 철 부품 자석 운반, 거리·종이 조건 통제 | 거리만 다른 두 실험, 종이만 다른 두 실험 설계 | 힘 관찰 렌즈 |
| 극성 복원 센터 | 기준 자석 두 극의 반응 확인 후 양끝 스티커 복원, 고리 번호·면·배치 조합 | 당겨 여는 문과 밀어 막는 안전문 조정, 기준 극 반전 | 극 표시 스티커 |
| 원격 제어 구역 | 연결을 유지하며 얼룩 위 실제 왕복 청소, 중간 점검소 정차 후 지정된 밀기·당기기로 운반 | 자석 위치·극·떼기를 써서 창고 경유 왕복 배송 | 원격 조작 손잡이 |
| 시민 발명 공방 | 목적 선택, 직접 조립, 시제품 성공/실패 시험, 개선한 현재 설계로 두 사용 조건 검증 | 당겨 고정하는 장치와 밀어내는 완충장치 설계 | 내 발명 설계도·광장 복구·축제·인증서 |

## 교육과정 근거

프로젝트에 합의된 [4과09-01]~[4과09-03]을 유지한다. 2026-10-24에 [충청북도교육청 공개 원문 PDF](https://www.cbe.go.kr/upload/dept-19/na/bbs_1437/2025/12/7FE4CF24-7583-F11C-85FC-22DF81DACFB2.pdf) 99쪽의 세 성취기준과 `src/settings-content.ts` 문구를 대조했다.

- 01: 재료 반응, 철과 알루미늄 비교, 가까움·멀어짐, 사이 물질과 비접촉 힘.
- 02: 같은 극·다른 극의 반응, 사라진 극의 추론, 고리의 실제 마주 보는 면, 운반 방향.
- 03: 생활의 불편을 정의하고 부품·위치를 설계, 실패를 근거로 개선, 다른 조건에서 검증.

과학 모형은 실제 힘의 크기·정밀 측정값을 주장하지 않는다. 현장 의뢰는 설명 모형임을 표시한다. 종이 비교 시 두 물체 프레임과 간격을 고정하고 종이만 겹쳐 표시한다. 실제 수업에서는 학생이 자기 말로 설명하는지와 실제 자석으로의 전이를 교사가 확인한다.

## 코드와 기록

- `inquiry-content.ts`: 학습 질문·예상·규칙·근거·오답 단서. 정답 위치는 문항별로 다르다.
- `inquiry-model.ts`: 설명/현장 조건/배송 방향/완료 판단의 순수 함수.
- `inquiry.ts`: 실제 실험을 감싸는 상태 흐름과 현장 조작 UI. 설명 전에 손조작 증거를 다시 검사한다.
- `mission-play.ts`: 실제 조작과 실험 증거. `mission-model.ts`가 강화된 완료 조건을 판정한다.
- `production.css`, `inquiry.css`, `quest-ui.ts`, `art.ts`: 새 화면 시스템과 생성 이미지 연결.

저장 스키마의 version 2는 유지한다. 기존 `Activity.values`에 탐구 상태·예상·근거·적용 기록을 보관하고, 새로운 조작 조건은 `mechanicsVersion=1`인 새 시도에 적용한다. 이전 v4 진행에 지나간 라운드의 새 조건을 소급하지 않는다. 구역을 다시 탐구할 때 기존 evidence와 발명 원본은 별도 사본으로 보호한다. 교사 전체 해금은 원래 기록에 저장되지 않는다.

## 디자인·에셋

기존 도시·실험실의 따뜻한 그림 스타일을 유지하고 크림색 연구 기록, 청록색 제목, 황동색 선택 상태로 정리했다. 6재료와 막대자석, 실험 장비 6종, 구역 장면, 자석 문, 안내 로봇을 신규 생성해 실제 조작물·예상 카드·현장 의뢰·기록 그림에 적용했다. 생성 장면의 부정확한 고리자석 그림은 제외하고 올바른 윗면/아랫면 장비 이미지로 조합한다. 물리적으로 정확해야 하는 극 문자·표시·화살표는 코드로 표시한다. 과거 기록에는 극 방향 정보가 없으므로 기록 그림의 자석은 중립색으로 표시하고 위치 기록임을 안내한다.

실제 생성 프롬프트·원본·투명도·규격·권리 범위는 [이미지 제작 기록](ART-PRODUCTION-20261024.md)에 있다. 기존 파일은 삭제하지 않는다.
